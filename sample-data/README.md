# 흙과불 도자기공방 시험 자료

해커톤 11번 고객사 "흙과불 도자기공방"이 가지고 있다고 한 자료 4종을 직접 만든 시험용 데이터입니다.
**회사·사람·연락처·수치는 모두 가상**입니다. 실제 업체 이름은 쓰지 않았습니다. 대신 문서 형식, 용어, 식약처 기준값 같은 수치는 실제 자료를 조사해 맞췄습니다(맨 아래 참고 출처). 연락처는 실제로 발급되지 않는 `010-0xxx` 국번대를 썼습니다.

기준일은 **2026-11-13**입니다. 이날을 기준으로 지난 수업, 앞으로 잡힌 예약, 단계가 서로 다른 작품이 섞여 있습니다.

## 자료 사이의 연결

- 흙·유약은 **코드로 서로 이어집니다.** 엑셀 작품 목록의 흙·유약 칸(예: `OG-C22 산화청자유`, `LF-125 Oatmeal Speckle`)은 공급처 PDF의 제품 데이터시트 제목과 같습니다. 수업 노트도 같은 코드를 씁니다.
  - 새터도재 `ST-…`(흙 13종), 온결유약 `OG-…`(15종), 빛가람세라믹 `BG-…`(12종), Larkfield `LF-…`(15종)
- 공방 설정은 다음과 같습니다.
  - 전기가마 1대로 산화소성만 합니다. 초벌 800℃, 재벌 1240℃입니다.
  - 가마는 작품이 30점 이상 모이면 돌립니다.
  - 정원은 일반 8명, 물레 6명입니다(물레 6대).
  - 대표 문정호, 류세아 강사(예약·DM), 권태민 강사(수업 노트)가 운영합니다.

## 정해 둔 값 (인터뷰에서 "미정"이던 것)

- **금액**(실제 시세 참고)
  - 핸드빌딩 원데이 60,000원(2시간)
  - 물레 원데이 75,000원(2시간 30분)
  - 정규반 4주 280,000원
  - 택배비 4,000원, 선물 포장 5,000원
- **일정**
  - 원데이: 수·금 19:30, 토 14:00·16:30, 일 11:00·14:00
  - 정규반: 화 19:30 물레, 목 19:30 핸드빌딩, 토 10:30 물레
  - 추석·개천절·한글날·성탄절은 휴강
- **규칙을 정하지 않고 사례로만 남긴 것**: 노쇼, 대기자, 가마 파손 처리, 단체 견적 기준. 엑셀 메모와 수업 노트에 "기준 없음 / 대표님과 상의"로만 나옵니다.
