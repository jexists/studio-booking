# backend.sh 포트 정리 설계

## 목표

`backend.sh` 실행 시 설정된 백엔드 포트를 점유한 기존 프로세스를 자동으로 종료하고 NestJS 개발 서버를 시작한다.

## 동작

1. 포트를 점유한 PID를 찾는다.
2. 각 PID에 `SIGTERM`을 보내고 최대 5초간 포트 해제를 기다린다.
3. 여전히 점유 중인 PID에는 `SIGKILL`을 보내고, 포트가 비워졌는지 다시 확인한다.
4. 종료에 실패하면 점유 프로세스 정보를 포함해 오류로 끝낸다. 해제되면 기존 DB·Prisma·NestJS 실행 절차를 계속한다.

## 범위와 안전성

- 포트를 점유한 프로세스만 대상으로 한다. 다른 포트와 설정은 바꾸지 않는다.
- `lsof`가 없는 환경에서는 기존처럼 포트 확인을 건너뛴다.
- API·DB 스키마에는 변경이 없다.

## 검증

- 셸 문법 검사(`bash -n`)를 실행한다.
- 3001 포트에 임시 리스너를 띄운 뒤 `backend.sh`의 포트 정리 단계가 리스너를 종료하는지 확인한다.
