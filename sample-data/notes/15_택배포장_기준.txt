택배 포장 기준
정리: 권태민 (대표님 기준 받아 적음) / 최초 작성 2024.08 / 최종 수정 2026.10

대표님이 정한 기준을 단계별로 풀어 적은 것. 기준 자체는 대표님 것이고, 머그·접시·화병별 요령이나 일화는 내가 덧붙임.
택배 파손은 "재제작"이 원칙(대표님). 그러니까 포장 잘못하면 수강생 작품 다시 만들어야 하고, 원데이 작품은 수강생이 다시 와야 함 → 포장이 제일 싸게 먹힘.

■ 대표님 기준 (원문 그대로)
1) 작품마다 에어캡 2겹 이상
2) 안쪽 공간(머그 안 등)은 종이 완충재로 채움
3) 박스 안 사방 5cm 이상 완충
4) "취급주의/깨지기 쉬움" 스티커
5) 박스 흔들어 봤을 때 소리 안 나야 함
+ 손잡이·주둥이는 따로 감싼다.

■ 비용·접수 기본
- 택배비 4,000원, 수강생 부담. 제주·도서산간은 추가.
- 선물 포장 5,000원 별도(아래 6번).
- 택배 신청은 수업 때 또는 완성 연락 받고 DM으로. 류쌤이 작품 목록 "수령 방법" 칸에 "택배" 표시하고 주소 받음.
- 입금 확인 후 포장. 입금 전 포장해두는 건 OK, 발송은 X.
- 완성품은 E선반, 택배 대기 작품은 E-5로 옮김.

==================================================
1. 준비물
==================================================
□ 에어캡(뽁뽁이) 롤 — 큰 알 / 작은 알 둘 다. 작은 알은 손잡이·주둥이용.
□ 종이 완충재(크라프트지 구긴 것) — 신문지는 잉크 묻어서 안 씀(2024.09 흰 머그에 글씨 묻음).
□ 박스 소/중/대 (아래 3번)
□ 스티커 "취급주의 / 깨지기 쉬움"
□ 박스테이프, 마스킹테이프, 네임펜
□ 작품 목록 출력본 (이름·작품 확인용)
□ 휴대폰 (포장 전·후 사진)

==================================================
2. 단계별 포장 순서
==================================================
STEP 0. 작품 확인
- 작품 목록이랑 바닥 이니셜+날짜 대조. 이름 틀려서 다른 사람 머그 보낸 적 있음(2025.01, 같은 날 같은 이니셜 KJ 두 명). → 이후 이니셜 뒤 숫자 확인 필수.
- 금·이 간 것 없는지 손가락으로 입술·굽 한 바퀴 훑어봄. 이상하면 포장 멈추고 대표님께.
- 포장 전 사진 1장(작품 + 바닥 이니셜). 파손 접수 때 "보낼 땐 멀쩡했다" 근거로 씀.

STEP 1. 손잡이·주둥이 먼저
- 작은 알 에어캡을 손잡이 크기로 잘라 손잡이 안쪽 구멍까지 감쌈 → 마스킹테이프로 고정.
- 주전자·피처 주둥이도 같은 방식. 주둥이는 종이 조금 말아 끝에 덧댐.

STEP 2. 안쪽 채우기
- 머그·컵·볼 안에 종이 완충재를 꽉 차게. 손으로 눌렀을 때 들어가지 않을 정도.
- 너무 세게 쑤셔 넣으면 얇은 기물은 오히려 금 감. "꽉 차되 밀어붙이지 않게".

STEP 3. 에어캡 2겹 이상
- 큰 알 에어캡으로 몸통 전체 2바퀴 이상. 볼록한 면이 작품 쪽.
- 위·아래(입구·굽)도 접어서 덮기. 굽이 제일 약함.
- 테이프는 에어캡끼리만. 작품에 직접 붙이지 않음(무광 유약에 자국 남음).

STEP 4. 박스에 넣기 — 사방 5cm
- 바닥에 종이 완충 5cm 이상 먼저 깔고 작품 넣음.
- 옆면·위 모두 박스 벽까지 5cm 이상 → 자로 한 번 재볼 것. 처음엔 다들 3cm 정도로 함.
- 작품 2개 이상이면 작품끼리도 사이에 종이 5cm. 작품끼리 닿으면 안 됨.

----- p.74 -----
STEP 5. 흔들기 테스트
- 박스 닫고 테이프 붙이기 전에 양손으로 들고 앞뒤·위아래 흔들어봄.
- 달그락/사각 소리 나면 → 다시 열고 빈 곳 채움. 소리 안 날 때까지.
(대표님: 흔들어서 소리 나면 그건 택배 기사님이 대신 흔들어주는 거랑 같다.)

STEP 6. 밀봉·스티커
- H자로 테이프(위 가운데 + 양 끝).
- "취급주의/깨지기 쉬움" 스티커 윗면 1장 + 옆면 2장 이상.
- 박스 위에 "↑ 이쪽이 위" 화살표 네임펜으로.

STEP 7. 포장 후 사진
- 밀봉된 박스 사진 1장(스티커 보이게). 작품 목록 비고에 "발송일 / 박스 크기" 기록.

==================================================
3. 작품별 포장 요령
==================================================
[머그·컵]
- 손잡이 먼저 따로(STEP 1) → 안쪽 종이 → 에어캡 2겹.
- 머그 2개 이상이면 입구끼리 마주보게 넣지 말 것(입술끼리 부딪힘). 나란히 세우고 사이 종이.
- 손잡이 방향은 박스 벽 쪽 말고 가운데 쪽.

[접시]
- 세워서 넣는 게 눕히는 것보다 덜 깨짐(대표님 경험). 특히 지름 15cm 이상.
- 접시 여러 장 → 사이마다 에어캡 1겹 + 종이 1장, 겹쳐서 다시 전체 에어캡 2겹.
- 테두리(림)가 제일 약함 → 테두리만 작은 알 에어캡 한 줄 더 두름.
- 오목한 면 안쪽에도 종이 채움.

[화병]
- 입구 좁은 건 안쪽 종이 넣기 어려움 → 종이를 길게 말아서 넣음. 다 못 채워도 목 부분까진.
- 목이 가늘고 긴 화병은 목 부분 작은 알 에어캡 추가.
- 박스는 화병 높이 + 10cm 이상(위아래 5cm씩).
- 크랙유·라바유·결정유 등 표면 울퉁불퉁한 건 에어캡이 걸려서 찢어질 수 있음 → 얇은 종이 1장 먼저 싸고 에어캡.

[소품·트레이·수저받침]
- 작은 건 여러 개 → 각각 에어캡 후 작은 박스에 모아 넣고, 그 박스를 다시 큰 박스에(이중 박스).

==================================================
4. 박스 크기 기준
==================================================
| 박스 | 안쪽 크기(대략) | 넣는 것 |
| 소 | 25×20×20cm | 머그·컵 1개, 작은 볼 1개 |
| 중 | 35×28×25cm | 머그 2~3개, 접시(지름 20cm 이하) 1~2장 |
| 대 | 45×35×35cm | 화병, 접시 여러 장, 정규반 4주 작품 묶음 |
- 기준은 "작품 + 사방 5cm". 그거 안 되면 한 단계 큰 박스.
- 정규반 수료생 작품은 보통 대 1개 또는 중 2개. 박스 2개 되면 택배비도 2건 → 신청 받을 때 류쌤이 미리 안내함.
(2025.10 추가) 박스 재활용(가마 소모품 들어온 박스 등) 써도 되는데, 겉에 다른 회사 이름 크게 있으면 흰 종이로 덮을 것.

==================================================
5. 택배사 접수
==================================================
- 공방 거래 택배사 1곳(계약 건). 방문 수거는 평일 오후. 토·일 포장한 건 월요일 수거.
- 접수할 때 품목 "도자기(깨지기 쉬움)" 선택 → 취급주의 표시 됨.
- 송장번호는 작품 목록 비고 + 수강생에게 DM(류쌤). "OO님 작품 오늘 발송했어요. 송장번호 OOO입니다. 받으시면 바로 열어서 확인 부탁드려요."
- "받으시면 바로 열어서 확인" 문장 꼭 넣을 것 → 파손이 늦게 발견되면 택배 중 깨진 건지 확인이 어려움.
- 제주·도서산간 추가 운임은 접수 때 나오는 금액 그대로 수강생에게 안내.
----- p.75 -----

==================================================
6. 선물 포장 (5,000원)
==================================================
- 구성: 크라프트 선물 상자 + 종이 완충(흰색 얇은 종이) + 리본(베이지/네이비 2종) + 공방 카드 1장(손글씨 메시지 원하면 받아서 써드림).
- 순서: 작품 얇은 종이로 감싸기 → 선물 상자 안에 흰 종이 완충 → 작품 → 위에 카드 → 뚜껑 → 리본.
- 택배 + 선물 포장 같이: 선물 상자째로 에어캡 2겹 → 택배 박스에 넣고 사방 5cm. 선물 상자가 "작품 하나"라고 생각하면 됨.
- 선물 상자 안에도 작품이 흔들리지 않게. 선물 받는 사람이 열었을 때 깨져 있으면 최악.
- 가격표·작품 목록 쪽지 넣지 말 것.
- 방문 수령 선물 포장은 쇼핑백 포함.

==================================================
7. 택배 파손 접수 → 재제작
==================================================
택배 중 파손은 재제작이 원칙(대표님 기준). 가마 안에서 깨진 건 다름 → 16번 노트.

[사진 받기 — 이 순서대로 요청]
1) 택배 박스 겉면 전체(찌그러짐·젖음 있는지)
2) 송장 부분
3) 박스 연 상태(완충재 그대로 있는 모습)
4) 깨진 작품 전체
5) 깨진 부분 가까이
→ DM 문장: "많이 속상하시죠. 죄송합니다. 확인을 위해 박스 겉면, 박스 연 모습, 깨진 부분 사진을 보내주실 수 있을까요? 확인 후 다시 만들어드릴게요."
→ 깨진 조각 버리지 말고 일단 보관해달라고 함(택배사 접수 때 필요할 수 있음).

[재제작 흐름]
1) 사진 받으면 포장 전·후 사진(STEP 0·7)이랑 같이 대표님께 공유
2) 택배사 파손 접수는 대표님이 함
3) 재제작 방식
   - 원데이 작품: 수강생이 다시 와서 만드는 게 기본. 같은 수업 빈자리로 일정 잡음(류쌤).
     → 못 오시는 분: 강사가 비슷하게 만들어 드리는 경우도 있었음. 이건 대표님 확인 후.
   - 정규반 작품: 수강생과 상의해서 다음 정규반 시간 등에 다시 만듦. 같은 유약으로.
4) 재제작품은 작품 목록에 "재제작(택배 파손, 원 작품 날짜)" 표시. 이니셜 뒤에 R.
5) 재제작품 다시 보낼 때 택배비 → 지금까지는 공방이 냈음. 따로 정한 기준은 아니라 매번 대표님 확인.
6) 재제작 기간도 3~4주 걸린다고 안내. 가마 30점 기준 똑같음.

[기록 — 택배 파손]
- 2024.11 머그 1개, 손잡이 부러짐 → 손잡이 따로 안 감쌌던 때. 이후 STEP 1 생김. 수강생 재방문해서 재제작.
- 2025.04 접시 2장 중 1장 테두리 깨짐 → 눕혀서 겹쳐 넣었음. 이후 "접시는 세워서" 추가. 정규반 수강생이라 다음 기수 때 재제작.
- 2025.12 화병 목 부러짐(제주) → 박스 높이 여유 3cm였음. 강사(나)가 비슷하게 만들어 보냄, 대표님 확인함.
- 2026.06 머그 2개 모두 멀쩡, 박스만 찌그러짐 → 사진 받고 이상 없음 확인. 재제작 X.

8. 자주 하는 실수 / 체크리스트
==================================================
[실수 모음]
- 에어캡 1겹만 감음 → 2겹 이상! 머그는 3겹 해도 됨.
- 박스가 작아서 사방 5cm 안 나오는데 "이 정도면 되겠지" → 2025.12 화병 사고가 딱 이거.
- 흔들기 테스트 생략 → 바쁠 때 제일 많이 빠뜨림. 토요일 원데이 연속인 날 오전에 포장하지 말고 평일에.
- 스티커 윗면에만 붙임 → 택배는 옆으로 쌓이기도 함. 옆면도.
----- p.76 -----
- 작품 목록 확인 안 하고 포장 → 다른 사람 작품 보냄(2025.01).
- 테이프를 작품에 직접 → 무광 유약 OG-M61, LF-184에 끈적이 자국. 지우다가 표면 상함.
- 젖은 종이 완충재 사용 → 박스 눅눅해지고 작품에 얼룩. 비 오는 날 창고 종이 확인.

[포장 전 최종 체크]
□ 작품 목록 이름·이니셜 대조
□ 금·이 확인 (손가락으로 입술·굽)
□ 포장 전 사진
□ 손잡이·주둥이 따로 감쌈
□ 안쪽 종이 채움
□ 에어캡 2겹 이상
□ 사방 5cm
□ 흔들어도 소리 안 남
□ 취급주의 스티커 윗면 + 옆면
□ 포장 후 사진, 작품 목록에 발송일·박스 크기
□ 송장번호 류쌤 전달 (DM 발송)

==================================================
9. 정해지지 않은 것 (물어보면 대표님께)
==================================================
- 해외 배송: 해본 적 거의 없음, 기준 없음.
- 같은 수강생 여러 수업 작품 묶어 보내기: 지금까지는 묶어서 1건으로 보내드림(택배비 1건). 다만 박스 2개 되면 2건. 묶을지 말지 애매하면 류쌤 확인.
- 택배 받고 며칠 지나서 파손 연락: 언제까지 받아줄지 정해진 거 없음. 대표님께.
- 퀵·당일 배송 요청: 기준 없음. 비용 전액 수강생 부담이라도 대표님 확인 후.
- 포장 상태로 방문 수령: 가능. 대신 운반 중 파손은 택배 파손이 아니라서 처리 방식 애매 → 대표님께.
(대표님 2026.05: 포장 기준은 바꿀 생각 없음. 대신 박스 재고 떨어지지 않게 류쌤이 월말에 체크.)

==================================================
10. 정규반 수료 작품 묶음 포장 요령
==================================================
정규반 4주 하면 작품이 보통 5~10점. 한 박스에 다 넣으려다 사고 남.
- 무거운 것(볼·접시) 아래, 가벼운 것(컵·소품) 위. 층 사이 종이 완충 5cm.
- 접시는 박스 벽 한쪽에 세워서 모으고, 반대쪽에 머그류.
- 10점 넘거나 대 박스 무게가 들기 힘들 정도면 박스 2개로 나눔 → 택배비 2건(수강생 부담) 미리 안내.
- 작품 목록 출력본을 박스 안 맨 위에 넣어서 수강생이 개수 확인할 수 있게. 가격 적힌 건 빼고.
