정규반 4주 커리큘럼 (물레반 / 핸드빌딩반)
작성: 권태민 / 최초 작성 2024.03 / 최종 수정 2026.09

정규반은 원데이랑 완전히 다름. 4주 동안 같은 사람을 만나니까 "본인이 직접 다 해보게" 하는 게 목표. 굽깎기·시유를 강사가 대신 해주는 원데이와 달리, 정규반은 수강생이 직접 함(4주 차 시유는 강사 보조).
처음 맡을 때 제일 많이 실수하는 것: 1주 차에 욕심내서 너무 많이 가르치는 것. 1주 차는 흙 만지는 재미만 느끼게 할 것.

■ 기본 정보
- 4주 과정, 주 1회 같은 시간, 회당 2시간 30분
- 가격 280,000원 (흙·소성비 포함). 개인 흙 추가 시 별도(아래 5번).
- 정원: 핸드빌딩반 8명 / 물레반 6명(물레 6대)
- 시간표:
  | 요일 | 시간 | 반 | 정원 |
  | 화 | 19:30~22:00 | 물레반 | 6 |
  | 목 | 19:30~22:00 | 핸드빌딩반 | 8 |
  | 토 | 10:30~13:00 | 물레반 | 6 |
- 토 10:30 물레반 끝나고 14:00 원데이 있는 날 많음 → 13:00 정각에 물레 청소 시작해야 함. 정규반 수강생 중 남아서 더 하고 싶다는 분 있으면 13:20까지만.
- 같은 주 안에 물레반이 화·토 두 번 있으니까 물레반 보강은 비교적 쉬움. 핸드빌딩반은 목요일 하나뿐이라 보강 어려움 → 아래 4번.
- 4주 연속이 원칙. 중간에 공방 휴무(명절 등) 끼면 그 주는 건너뛰고 한 주 밀림 → 첫 수업 때 날짜표 나눠줄 것.

1. 물레반 4주
==================================================

[1주 차 — 중심잡기, 원통]
- 흙: 조합토(물레용) ST-M610. 가소성 좋아서 초보 물레용. 백자토 ST-W110은 2주 차부터.
- 반지·시계 빼기, 앞치마, 물레 앉는 자세(엉덩이 앞쪽, 팔꿈치 허벅지 고정).
- 꼬박밀기(국화꼬박) 5분 시범 → 실제로는 강사가 미리 밀어둔 흙 씀. 직접 해보는 건 3주 차에.
- 중심잡기만 60분 넘게 반복. 지루해하면 중간에 구멍 내기까지 해보게 함.
- 목표: 높이 8cm 원통 1개. 못 해도 됨. "오늘 원통 하나 나오면 잘하신 거예요."
- 작품은 1~2개 남김(나머지 재활용).
- 마무리 때 작품 바닥 옆면 연필 이니셜 + 정규반 전용 선반(B-5) 올리기.

[2주 차 — 컵·볼, 굽깎기 첫 경험]
- 흙: 백자토(일반) ST-W110로 바꿔봄. 조합토보다 매끈하고 덜 버팀 → 처음엔 다들 무너뜨림. 원하면 조합토 계속 써도 됨.
- 수업 전반 60분: 1주 차 작품 굽깎기. 반건조 상태여야 함 → 1주 차 작품이 너무 말랐으면 비닐 씌워 수분 조절해둘 것(수업 전날 확인!).
  - 너무 마른 건 굽깎기 하다 깨짐. 그럼 그냥 바닥만 정리하고 넘어감.
- 후반 90분: 컵 2~3개, 볼 1개. 입술(구연) 정리는 가죽(샤미) 사용.
- 굽 깎고 나면 바닥에 이니셜+날짜 새김(조각칼).

[3주 차 — 손잡이, 접시, 꼬박밀기]
- 꼬박밀기 직접 해보기(10분). 손목 아프다는 분 많음 → 무리하지 말라고 함.
- 2주 차 작품 굽깎기 + 손잡이 붙이기(당겨 뽑기 손잡이 시범).
- 접시(넓은 기물) 도전: 바닥 넓게 펴고 압축(스펀지로 눌러주기) 안 하면 S자 금 감. 주의!
- 이 시점에서 1주 차 작품은 초벌 들어갔을 수도 있음 → 가마 사정에 따라 다름. 대표님께 초벌 일정 미리 여쭤볼 것.

----- p.62 -----
[4주 차 — 시유, 마무리]
- 초벌 나온 작품에 직접 시유(담금 / 붓 / 흘리기). 유약은 정규반에선 선택지 넓게 줌(아래 6번 유약 안내).
- 굽 부분 왁스(BG-W91) 바르기, 천목유 OG-I41·LF-142처럼 흐르는 건 굽 1cm 남기기.
- 시유 못 한 작품(아직 초벌 안 된 것) → 강사가 대신 시유. 수강생한테 원하는 색 받아서 작품 목록에 기록.
- 수령 안내: 재벌까지 보통 3~4주, 가마 30점 모여야 돌아서 범위로 말할 것. 완성 후 60일 보관. 택배 원하면 4,000원.
- 다음 기수 연장 문의 많음 → 재수강 할인은 정해진 거 없음. "대표님께 여쭤볼게요"로만 답할 것.

2. 핸드빌딩반 4주 (목 19:30)
==================================================

[1주 차 — 핀칭, 코일링]
- 흙: 핸드빌딩 샤모트토 ST-H620. 샤모트 20% 들어 있어서 판성형·코일링할 때 덜 갈라짐, 수축률도 9%로 작음.
- 핀칭으로 작은 그릇(찻잔 크기) 1개 → 코일링으로 화분형 1개.
- 코일 굵기 1cm 일정하게. 이음 부분 안팎으로 문질러서 메우기.
- "샤모트토는 손이 좀 까끌까끌해요"라고 미리 말함. 손 거친 분은 고무장갑 줌.

[2주 차 — 판성형]
- 밀대 + 7mm 각목 가이드. 판 떠서 사각 접시, 원통 머그.
- 이음새: 긁기 + 슬립 + 눌러주기. 판이 너무 젖었으면 30분 정도 말렸다가 세움(가죽 경도).
- 원하면 백자토 ST-W110로 바꿔도 됨. 대신 판이 더 잘 처짐.

[3주 차 — 표면 장식, 분청 기법 맛보기]
- 분청토 ST-B310(회흑색)로 작은 접시 만들어서 백토 화장토 ST-SL120으로 귀얄(붓질), 덤벙(담그기) 해봄.
- 이때 "분청은 유약 이름이 아니라 기법"이라는 설명을 꼭 함. 분청토 위에 화장토 바르고 → 위에 분청 투명유 OG-P31 입혀서 구움.
- 상감 원하는 분: 색 화장토 세트 ST-SL130(5색)으로 긁고 메우기. 시간 많이 걸려서 작은 면적만.
- 언더글레이즈(BG-U20) 그림도 이때. 초벌 전 생지에 그려도 되고, 초벌 후 그려도 됨.

[4주 차 — 시유, 손잡이 보강, 마무리]
- 물레반과 같음. 초벌 나온 것 직접 시유.
- 흙 섞어 쓴 작품(백자토+분청토 붙인 것 등)은 수축률이 달라서 이음새 갈라질 수 있음 → 3주 차 때 미리 말려야 함.
- 마지막 30분은 작품 전체 사진, 다음 기수 안내.

4. 결석·보강 처리 흐름
==================================================

----- p.63 -----
규칙(공방에서 정한 것): 정규반 결석 시 **같은 주 안의 다른 정규반**에 빈자리가 있을 때만 보강 가능. 강사가 확인한 뒤 안내.
→ 원데이 수업으로 대신하는 건 규칙에 없음. 다음 주로 넘기는 것도 규칙에 없음. 그런 요청 오면 대표님과 상의.

[흐름]
1) 결석 연락 받음 (보통 류쌤이 DM으로 받음 → 강사 단톡에 공유)
2) 같은 주 다른 정규반 확인
   - 화 물레반 결석 → 같은 주 토 10:30 물레반 빈자리 확인
   - 토 물레반 결석 → 같은 주 화 19:30 물레반 (이미 지났으면 보강 불가)
   - 목 핸드빌딩반 결석 → 같은 주에 다른 핸드빌딩 정규반 없음. 물레반 빈자리로 가는 건 내용이 달라서 대표님 확인 필요.
   ※ "같은 주"를 월~일로 보는지 결석일 기준 7일로 보는지 정해진 거 없음. 지금까지는 월~일로 처리함.
3) 빈자리 확인: 물레반은 6대라서 6명 꽉 찼으면 무조건 불가. 핸드빌딩반은 8명.
4) 진도 확인: 보강 들어가는 반이 몇 주 차인지. 진도가 다르면 그날은 자기 진도대로 개인 작업하게 함(강사 부담 늘어남 → 그 반 강사에게 미리 말할 것).
5) 수강생에게 안내: "이번 주 토요일 10:30 물레반에 자리가 있어서 보강 가능합니다. 오실 수 있으면 알려주세요."
6) 보강 확정되면 작품 목록·출석부에 "보강(화→토)" 표시.
7) 빈자리 없으면: "이번 주에는 다른 정규반 자리가 없어서 보강이 어렵습니다" 그대로 안내 → 추가 요청(환불·이월 등) 오면 대표님께. 강사가 약속하지 말 것.

[사례]
- 2025.05 화 물레반 이OO님 출장 결석 → 그 주 토 물레반 5명이라 1자리 있음 → 보강 완료.
- 2025.09 목 핸드빌딩반 박OO님 결석 → 같은 주 핸드빌딩 정규반 없음 → 대표님 상의 → 이번엔 다음 기수 1회 들어오시는 걸로 대표님이 직접 정함. ※ 이건 그때 한 번 그렇게 한 것, 규칙 아님.
- 2026.02 토 물레반 최OO님 → 이미 화요일 지나서 같은 주 보강 불가 안내. 수강생 서운해하심. 다음부터 첫 수업 때 보강 규칙을 미리 말하기로 함.
- 4주 중 2회 이상 결석 → 정해진 처리 없음, 대표님과 상의.

5. 개인 흙 구매
==================================================
- 정규반 기본 흙은 수강료에 포함(1인당 대략 회당 1.5~2kg 쓰는 정도).
- 큰 작품·많이 만들고 싶은 분은 개인 흙 구매 → 별도 비용. 가격은 대표님이 그때 단가 보고 정함 (류쌤 가격표 참고).
- 단위: 새터도재 10kg 비닐 진공 포장 단위로 판매.
  - 백자토(일반) ST-W110 — 제일 많이 사감
  - 고급백자토 ST-W210 — 입자 고와서 물레 숙련자용. 초보가 사겠다고 하면 "조금 더 하시고 나서" 권함. 1250~1280℃ 권장이라 우리 1240℃ 재벌에선 살짝 덜 익을 수 있음 → 대표님 확인.
  - 흑토 ST-K710 — 1250℃ 이상 부풂 주의. 우리 재벌 1240℃에서 쓰긴 하는데 가마 위치 신경 씀.
  - 적토(홍토) ST-R810 — 1240℃에서 휨·부풂 가능. 사겠다고 하면 미리 경고!
  - 라쿠토 ST-RK910 — 식기 불가, 장식용. 우리 가마 재벌 온도에서 못 씀. 팔지 않음.
- 개인 흙에는 이름 크게 쓴 테이프 붙여서 흙 보관함 아래 칸에. 마르면 물 뿌려서 비닐 다시.
- 개인 흙 작품도 소성비는 수강료에 포함 (4주 동안). 수료 후 계속 굽고 싶다는 문의 → 기준 없음, 대표님과 상의.

6. 정규반 유약 안내 (4주 차 시유용)
==================================================
정규반은 선택지 넓게. 대신 식기 안 되는 유약은 반드시 먼저 말할 것!
- 식기 OK 기본: 투명유(유광) OG-T01, 미색 유광유 OG-N16, 산화청자유 OG-C22, 분청 투명유 OG-P31, 천목유 OG-I41, 하늘유 OG-B81, 매트백유 OG-M61, LF-125, LF-138 Celadon Mist, LF-142 Floating Blue
- 수입 유약(LF-)은 Cone 5/6이라 우리 1240℃보다 낮음 → 흘러내림. 대표님이 가마 아랫단 + 받침에 놓음. 굽 1cm 꼭 남기기.
- 장식용만: 크랙유 BG-K31(식기 비권장), 라바유 BG-V41, LF-190 Midnight Crawl, LF-205 Lava Rose, 펄 라스터 BG-P71
- 금채 BG-G61 / 백금채 BG-G62: 정규반 요청 시만. 3차 소성 필요, 입술 닿는 곳 금지, 전자레인지·식기세척기 불가.
- 청자 원하면 OG-C22 또는 LF-138. 환원용 청자유 OG-C21은 우리 산화가마에서 황록·올리브색 나옴. (2024.11에 모르고 썼다가 수강생 머그 4개 올리브색 됨)
주의! 머그·컵 만든 분이 크랙유·라바유 고르면 "이건 장식용이라 음료 담으시면 안 돼요" 확실히 말하고 작품 목록 비고에 "장식용 안내함" 적을 것. 나중에 "몰랐다"는 연락 온 적 있음.

7. 첫 수업 때 꼭 말할 것 (안내 멘트)
==================================================
2026.02 보강 서운 사건 이후로 첫 수업 시작 5분은 안내 시간으로 씀. 종이 한 장 나눠주고 같이 읽음.
- 4주 날짜표 (휴무 끼면 밀린 날짜까지)
- 결석하면: 같은 주 다른 정규반 빈자리 있을 때만 보강. 미리 연락 주면 강사가 확인해서 안내. "다음 주로 미루기"는 안 된다고 말함 → 정확히는 "규칙에 없어서 대표님과 상의해야 한다".
- 작품 수령: 마지막 수업 끝나고도 재벌까지 3~4주. 가마 30점 모여야 돌아서 범위로만 안내 가능.
- 보관: 완성 후 60일, 이후 연락드리고 처분.
- 택배: 4,000원, 제주·도서산간 추가. 정규반은 작품 많아서 박스 2개 될 수 있음.
- 식기 안 되는 유약 있음 → 4주 차에 다시 설명.
- 가마에서 깨질 수 있음 → "드물지만 생길 수 있고, 생기면 대표님이 직접 연락드려 상의해요." 정도만. 보상 얘기 먼저 꺼내지 말 것(16번 노트).

[물레반]
- 1주 차: 페달 너무 빨리 밟음 → 흙이 날아감. "중심잡기는 빠르게, 벽 올릴 땐 천천히" 반복.
- 1주 차: 손목 꺾고 미는 분 → 손목 아프다고 함. 팔꿈치 고정 다시.
- 2주 차: 굽깎기 때 너무 깎아서 바닥 뚫림. 손가락으로 두드려 소리 들어보게 함(통통 → 얇음).
- 3주 차: 손잡이 당겨 뽑기 → 다들 너무 얇게 뽑음. 손잡이 두께 최소 8mm.
- 4주 차: 유약 담금 시간 너무 김(5초 이상) → 두꺼워서 흘러내림. "하나, 둘, 셋" 세고 빼기. 담금은 3초 전후.

9. 수료 후 문의 대응
==================================================
- "다음 기수 바로 이어서 듣고 싶어요" → 다음 기수 같은 요일 자리 있는지 류쌤 확인. 정원(물레 6/핸드 8) 넘으면 불가.
- "할인 있어요?" → 재수강·정규반 할인 정해진 거 없음. 대표님께.
- "작업실만 빌려 쓸 수 있어요?(자유 작업)" → 그런 프로그램 없음, 대표님과 상의.
- "남은 개인 흙 가져가도 돼요?" → 본인이 산 흙이면 가져감. 수강료 포함 흙은 공방 것.
- "제 작품 언제 다 나와요?" → 작품 목록에서 선반 위치 확인 후 범위로 안내. 4주 차 시유 작품은 보통 수료 후 2~3주.
