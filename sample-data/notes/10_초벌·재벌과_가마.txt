[수업 노트 10] 초벌·재벌과 가마 (소성 스케줄, 재임, 가동 일지, 가마 사고)
작성: 권태민 / 최초 작성 2024.03 / 최종 수정 2026.10
----- p.47 -----

※ 가마는 원칙적으로 대표님 담당. 강사는 재임(쌓기)·일지·가마 열기를 돕는 정도. 새 강사는 처음 3번은 대표님 옆에서 보기만.
※ 우리 가마: 전기가마 1대, 약 0.3㎥, 산화소성 전용. 가스가마 없어서 환원소성 못 함 → 청자유(환원용) OG-C21, 진사유 OG-R91 색 안 나옴(07·09 노트).

1. 초벌과 재벌
- 초벌: 성형·건조 끝난 생기물을 800℃ 전후로 한 번 굽는 것. 흙이 단단해지고 물을 먹을 수 있게 돼서 유약이 붙음. 승온 약 8~9시간.
- 재벌: 시유한 작품을 1240℃ 산화소성(SK7 부근)으로 굽는 것. 흙이 자기화되고 유약이 녹아 유리질이 됨. 승온 약 11~12시간 + 최고 온도에서 30분 유지.
- 식는 데 하루 이상. 초벌·재벌 모두 가마 열기는 다음다음 날 오전이 기본.
- 공방 기본 흙·유약이 1240℃에 맞춰져 있음: 백자토 ST-W110(1230~1260℃), 분청토 ST-B310(1220~1250℃), 온결 유약 대부분 1220~1260℃.
- 1240℃에서 조심할 것: 흑토 ST-K710(1250℃ 이상 부풂 → 윗단 피하기), 적토 ST-R810(1180~1230℃라 1240℃에서 휨·부풂 가능 → 공방에선 거의 안 씀), 라쿠토 ST-RK910(900~1180℃, 식기 불가, 재벌 넣으면 안 됨), Larkfield 유약(cone 5/6, 흐름 → 아랫단+받침).

- 프로그램 2번(예전 초벌 빠른 스케줄)은 쓰지 말 것. 2024년에 시간 줄이려고 만들었다가 두꺼운 작품 터져서 폐기. 컨트롤러에는 아직 남아 있음.

3. 30점 이상 모이면 가동하는 이유
- 수강생이 제일 많이 묻는 것: "왜 완성 날짜가 정확히 안 나와요?"
- 이유: 전기가마 한 번 돌리는 전기료가 작품 수와 상관없이 거의 같음. 재벌이면 12시간 넘게 고온 → 전기료가 꽤 나옴. 5점 넣고 돌리면 1점당 비용이 너무 비쌈.
- 또 가마는 어느 정도 채워야 안에서 열이 고르게 돎. 너무 비면 윗단·아랫단 온도 차가 커짐(대표님 경험).
----- p.48 -----
- 그래서 공방 규칙: 작품이 30점 이상 모이면 가동. 초벌도 재벌도 같음. → 날짜가 들쭉날쭉.
- 수강생 안내 문구(류쌤이 DM에 쓰는 것): "가마는 작품이 일정 수량 모이면 굽기 때문에, 성형부터 완성까지 보통 3~4주, 가마 사정에 따라 더 걸릴 수 있어요."
- 성수기(연말·5월)는 원데이 많아서 1주에 2번도 돌림. 비수기(1~2월, 8월)는 2주 넘게 안 돌 때도 있음.
- 정규반 수강생이 "제 거 먼저 구워주세요"는 안 됨. 30점 기준 예외 없음(대표님 원칙). 단, 가마 칸 남을 때 테스트 타일로 채우는 건 OK.

4. 가마 재임(쌓기)
- 초벌: 작품끼리 닿아도 됨(유약 없으니까). 그릇 안에 작은 그릇 넣기, 입구 맞대기도 가능. 단 무거운 걸 위에 올리지 말 것. 가마 꽉 채우면 40~50점.
- 재벌: 작품끼리 절대 안 닿게. 간격 1cm 이상(유약이 끓으면서 옆으로 튐). 굽만 선반에 닿게. 선반에는 알루미나 워시(선반 보호막) 발라져 있음.
- 재벌 칸 배치 기준:
  · 아랫단: Larkfield 유약 전부, 천목유 OG-I41, 재유 OG-A51, 결정유 BG-X51 — 받침 필수
  · 중단: 흑토 ST-K710 작품, 일반 작품
  · 윗단: 일반 백자토 + OG-T01/OG-N16 등 안 흐르는 유약. 흑토·적토 금지
  · 열선 가까운 벽 쪽 2cm 이내 금지
- 선반 기둥(지주)은 3점 지지. 4개 쓰면 하나가 뜰 수 있음. 선반 위에 선반 올릴 때 기둥 위치 위아래 같게.
- 큰 접시는 가운데 처짐 → 이중굽(06 노트) + 선반 가운데에.
- 재임 끝나면 사진 2장(위에서, 앞에서). 가마 일지에 첨부. 나중에 깨진 작품 위치 찾을 때 필요.

5. 가동 일지 쓰는 법
- 가마 옆 클립보드 + 공방 공용 엑셀(가마 일지 시트) 둘 다. 클립보드에 먼저 쓰고 그날 안에 엑셀로 옮김.
- 칸:
| 칸 | 쓰는 법 | 예 |
| 회차 | 연도-번호 | 2026-047 |
| 종류 | 초벌 / 재벌 | 재벌 |
| 프로그램 | 컨트롤러 번호 | 3번 |
| 시작 | 날짜·시각 | 11/04 09:10 |
| 최고 온도 도달 | 시각 | 11/04 21:05 |
| 종료(전원 off) | 시각 | 11/04 21:35 |
| 가마 열기 | 날짜·시각, 열 때 온도 | 11/06 10:00, 62℃ |
| 작품 수 | 점 수 + 반별 | 33점(화물 9, 토물 11, 원데이 13) |
| 위치 메모 | 단별로 특이 작품 | 아랫단 LF-142 머그 4, 받침 O |
| 결과 | 깨짐·금·붙음·색 이상 | 1점 바닥 금(토물 B님 국그릇) |
| 담당 | 재임/열기 사람 | 재임 권, 열기 대표님 |
- 결과 칸은 빈칸으로 두지 말 것. 이상 없으면 "이상 없음"이라고 씀. 나중에 파손 상의할 때 대표님이 이 칸 봄.
- 사진은 재임 사진 2장 + 가마 열었을 때 1장.
- (2025.09 추가) 전기 계량기 숫자도 시작·끝 적기로 함(대표님이 회차별 전기료 계산함).

6. 가마 열 때 주의
- 100℃ 아래로 내려가기 전에는 열지 말 것. 급하게 열면 찬 공기 들어가서 작품이 "틱" 소리 나며 금 감(냉각 크랙). 특히 재벌.
- 원칙: 재벌은 다음다음 날 오전, 표시 온도 60℃ 이하. 초벌은 다음 날 저녁도 가능하지만 100℃ 이하 확인.
- 열기 전에 장갑(면장갑 + 내열 장갑), 작품 받을 상자·신문지 준비.
- 문 열고 바로 손 넣지 말고 1~2분 기다림. 선반·작품 아직 뜨거움.
----- p.49 -----
- 위에서부터 꺼냄. 선반 들 때 두 손, 기둥 쓰러지지 않게.
- 꺼내면서 하나씩 확인: 굽 붙음, 금, 유약 흐름, 색 이상. 이상 있는 건 따로 상자에 + 사진 + 일지 결과 칸.
- 유약 흘러 받침에 붙은 건 그 자리에서 억지로 떼지 말 것. 작업대로 옮겨서 대표님이 처리.
- 재벌 끝난 유약 표면에 날카로운 유약 방울(굽 근처) 있으면 다이아몬드 사포로 갈아냄. 수강생 손 베임 방지. 굽 바닥도 한 번씩 사포질.
- 완성 작품은 작품 선반(A~E)으로, 작품 목록에 위치 기록 → 류쌤이 수령 안내 연락. 완성 후 60일 보관.

7. 가마 안에서 깨지는 원인 (수강생 설명용 + 강사 점검용)
- 작품 파손(가마 안 깨짐·금 감)은 정해진 처리 기준 없음. 매번 대표님이 수강생과 상의. 강사는 원인 추정만 정리해서 대표님께 전달.
(1) 기포·공기방울: 꼬박밀기(반죽) 덜 해서 흙 속에 공기 → 초벌 때 부풀거나 터짐. 터지면 옆 작품까지 파편 튐. 핸드빌딩 덩어리 작품(속이 꽉 찬 것)도 같은 원리 → 두께 2cm 넘으면 속 파내라고 할 것.
(2) 건조 덜 됨: 겉은 말랐는데 속에 수분 → 초벌 1구간에서 수증기 팽창 → 터짐. 건조 7~14일 지키기. 손등에 대보고 차가우면 아직 젖은 것(11 건조 노트).
(3) 두께 차이: 바닥 두껍고 옆면 얇음, 손잡이·붙인 장식 이음새 → 수축 속도 달라서 금. 06 굽깎기 기준(차이 3mm 이내).
(4) 유약 흘러 선반에 붙음: 굽 안 닦음, 흐르는 유약 받침 안 깜, 두껍게 바름 → 떼다가 깨짐. 09 시유 노트.
(5) 냉각 중 급랭: 가마 일찍 열기.
(6) 흙·온도 안 맞음: 적토 ST-R810, 흑토 ST-K710 윗단 → 휨·부풂. 라쿠토 ST-RK910 재벌 넣음 → 녹아내림(공방에선 아직 사고 없음, 넣지 말 것).
(7) 메운 자리: 바닥 뚫고 메운 곳, 상감 들뜬 곳 → 금.
- 수강생 설명 순서: 원인 추정 → "도자기는 가마 안에서 어느 정도 확률로 이런 일이 생긴다" → 처리는 대표님이 따로 연락드린다. 강사가 혼자 재제작·환불 약속 금지.

8. 가마 사고·사례 기록 (일지에서 옮긴 것)
- 2024-011 초벌: 프로그램 2번(빠른 초벌)으로 돌림 → 핸드빌딩 원데이 소품 3점 터짐, 파편이 옆 머그 2점 깨뜨림. 프로그램 2번 폐기.
- 2024-033 재벌: 굽 안 닦은 머그 1점 선반에 붙음. 선반 한 장 그라인더 연마 + 알루미나 워시 다시. 반나절 걸림.
- 2025-008 재벌: OG-C21 청자유(환원용) 작품 7점 올리브색(07 노트 사건). 가마 문제는 아니었지만 일지 결과 칸에 "유약 코드 오류"로 기록.
- 2025-019 재벌: LF-142 머그 2점 윗단·받침 없음 → 선반 붙음, 1점 파손(09 노트).
- 2025-031 재벌: 흑토 ST-K710 컵 1점 윗단 부풂(08 노트). 흑토는 중간~아랫단으로.
- 2025-044 재벌: 가마 열 때 85℃였는데 손님 수령 약속 때문에 열었음 → 접시 1점 "틱" 소리 후 금. 그 뒤 60℃ 원칙 다시 강조(대표님).
- 2026-012 초벌: 정규반 덩어리 오브제(두께 4cm, 속 안 팜) 터짐. 120℃ 유지 2시간 줬는데도 터짐. 두께 2cm 넘으면 속 파기, 안 팠으면 초벌에서 빼기.
- 2026-039 재벌: 이상 없음, 34점. 재임 사진 비교용으로 잘 쌓은 예. 새 강사는 이 회차 사진 볼 것(공용 폴더 "가마 사진/2026-039").

9. 가마 관리
- 선반: 알루미나 워시 상태 매 재벌 전 확인. 벗겨진 곳 있으면 덧바름(물에 개서 붓으로 얇게, 하루 말림). 선반 윗면에만, 옆면·아랫면 금지(떨어져서 아래 작품에 붙음).
- 선반 휘었는지 분기마다 확인. 휜 선반은 뒤집어서 씀(휜 방향 반대로).
- 열선: 가마 벽 홈에서 빠져나온 데 없는지 눈으로 확인(전원 끈 상태에서만). 이상하면 손대지 말고 대표님.
- 가마 바닥: 유약 방울·흙 부스러기 재벌 전에 진공청소기로. 부스러기가 열선 홈에 들어가면 열선 수명 줄어듦.
- 환기: 가마 돌 때 환풍기 켜기. 초벌 300~600℃ 구간에 냄새 남(흙 속 유기물 타는 것). 수업 시간과 겹치면 창문도.
- 가마 돌 때 가마 주변 1m 안에 물건 두지 말 것. 겉면도 뜨거움. 수강생 아이 동반 원데이 때 특히 주의.
- 가마 가동 중에는 마지막 퇴근자가 컨트롤러 화면 사진 찍어서 단톡에 올림(진행 구간·온도). 대표님이 원격으로 확인.

10. 초벌 끝난 뒤
- 초벌 기물 확인: 금, 들뜬 화장토(07), 상감 떨어짐(08), 바닥 금. 이상 있으면 작품 목록 메모 + 사진.
- 초벌 후 금은 메울 수 없음. 시유하고 재벌하면 금이 더 벌어지는 경우가 많음. 수강생한테 미리 연락해서 그래도 진행할지 물어봄(류쌤 통해).
- 초벌 기물은 물을 잘 먹으니 시유 전까지 먼지 안 쌓이게 D-2~D-5 선반에 신문지 덮어 보관.
- 초벌 기물에 손 기름·크림 묻으면 유약 튕김(09 노트).

11. 재임·가동 체크리스트 (가마 문 닫기 전)
□ 작품 수 30점 이상(재벌·초벌 공통)
□ 재벌: 모든 작품 굽 확인(5mm / 흐르는 유약 1cm)
□ 재벌: Larkfield·천목유·재유·결정유 아랫단 + 받침
□ 재벌: 흑토 윗단 X, 적토·라쿠토 X
□ 재벌: 작품 간격 1cm 이상, 벽에서 2cm
□ 초벌: 두께 2cm 넘는 덩어리 속 팠는지, 건조 7일 이상인지
□ 선반 기둥 3점, 위아래 위치 같음
□ 재임 사진 2장
□ 컨트롤러 프로그램 번호(초벌 1번 / 재벌 3번) 확인. 2번 아님!
□ 일지 시작 칸 작성, 계량기 숫자
□ 환풍기 ON, 가마 주변 1m 정리

12. 자주 받는 질문
Q. 언제 완성돼요? → "가마는 작품이 30점 정도 모이면 굽기 때문에 보통 3~4주, 가마 사정에 따라 더 걸릴 수 있어요." 날짜 확답 금지. 가마 날짜 정해지면 류쌤이 연락.
Q. 왜 두 번 구워요? → 초벌로 단단하게 만들어야 유약을 바를 수 있고, 재벌에서 유약이 녹아 유리처럼 됨.
Q. 청자 진짜 색 안 나와요? → 우리 가마는 산화소성 전용이라 환원 비색은 못 냄. 산화청자유 OG-C22로 연한 청록까지.
Q. 깨졌는데 어떻게 돼요? → 처리 기준은 정해진 게 없고 대표님이 직접 상의드린다고 안내. 강사가 그 자리에서 약속하지 않음.
Q. 가마 구경해도 돼요? → 가동 중엔 안 됨. 식은 뒤 열 때는 정규반 수강생 1~2명 정도 옆에서 보는 건 OK(대표님 허락 시).

13. 가마 일정 짜는 흐름 (대표님 방식 정리)
- 월요일 오전: 굽깎기 끝나고 선반 돌면서 점 수 셈. 건조 선반(초벌 대기) / D-2~D-5(재벌 대기) 따로.
- 초벌 대기 30점 넘고, 그중 건조 7일 지난 게 30점 이상이면 → 초벌 가동 후보.
- 재벌 대기 30점 넘으면 → 재벌 가동 후보. 둘 다 넘으면 재벌 먼저(완성 기다리는 수강생 우선).
- 가마 한 번 돌면 시작~열기까지 2~3일 묶임. 초벌·재벌을 같은 주에 둘 다 하면 주 후반이 빠듯함.

- 예) 월 09시 재벌 시작 → 월 21시대 종료 → 수 오전 열기 → 수 오후 초벌 재임·시작 → 목 새벽 종료 → 금 오후 열기 → 주말 수업에 시유.
- 주말 원데이 수업(토 14:00·16:30, 일 11:00·14:00) 있는 날에는 재임·가마 열기 피함. 작업실 좁아서 동선 겹침.
- 정해지면 류쌤이 "이번 주 가마 일정"을 단톡 공지에 올림. 강사는 그걸 보고 수강생 문의에 답함.
- 30점이 안 모여 2주 넘게 밀리면 대표님 판단으로 테스트 타일·공방 판매용 기물로 채워서 돌리기도 함. 이건 대표님 결정, 강사가 임의로 하지 않음.

14. 새 강사 가마 교육 순서
① 1회차: 재벌 재임 보기 + 일지 쓰는 법. 대표님이 쌓는 순서 설명 들으면서 사진 찍기.
② 2회차: 가마 열기 보기 + 결과 칸 쓰기. 사포질 연습.
③ 3회차: 초벌 재임 직접(대표님 확인). 초벌은 실패해도 피해가 적어서 먼저.
④ 4회차 이후: 재벌 재임 직접, 대표님 최종 확인 후 문 닫기.
- 컨트롤러 조작(프로그램 선택·시작)은 4회차 이후에도 대표님 확인 받고 누름.
- 가마 열 때 온도 확인 → 60℃ 이하 아니면 열지 않는 건 1회차부터 바로 지킬 것.

15. 메모
- (대표님: 가마는 공방에서 제일 비싼 장비. 열선 갈면 며칠 수업 일정이 다 꼬임. 무리하지 말 것)
- (류쌤 의견: 완성 안내 연락 때 "가마에서 나온 날짜"를 같이 적어주면 60일 보관 기간 계산이 쉬움. 일지 열기 날짜를 작품 목록에도 복사하기로 함, 2026.02부터)
- (2026.10 수정) 재벌 3구간 속도 시간당 70℃ → 60~70℃로 적음. 겨울엔 60℃로 늦추면 유약 표면이 더 매끈하다는 게 대표님 경험. 컨트롤러는 대표님이 계절마다 바꿈.
