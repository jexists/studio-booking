가마 파손 안내 (가마 안에서 깨짐·금 감)
정리: 권태민 (대표님 기준 받아 적음) / 최초 작성 2024.10 / 최종 수정 2026.11

※ 먼저 읽을 것
가마 안에서 깨지거나 금 간 작품을 어떻게 처리할지는 **아직 정해진 기준이 없음**. 재제작을 할지, 환불을 할지, 다음 수업 할인을 할지 → 매번 대표님이 수강생과 직접 상의해서 정함.
강사는 (1) 상황 파악, (2) 사진, (3) 첫 연락(사과 + "대표님이 연락드린다")까지만. 보상 약속 절대 하지 말 것.
택배 중 파손은 다름 → 재제작이 원칙(15번 노트). 헷갈리지 말 것.

==================================================
1. 가마 안에서 깨지는 원인
==================================================
우리 가마: 전기가마 1대(약 0.3㎥), 산화소성 전용. 초벌 800℃ 전후(8~9시간 승온), 재벌 1240℃(SK7 부근, 11~12시간 승온 + 30분 유지), 식는 데 하루 이상. 작품 30점 이상 모이면 가동.

[초벌 때 깨짐 — 대부분 수분·두께 문제]
- 덜 마른 작품: 안에 남은 물이 수증기로 터짐. 조각이 튀어서 옆 작품까지 깨뜨림. 제일 위험!
  → 건조 7~14일. 장마철·겨울엔 더 걸림. 볼에 대봤을 때 차가우면 아직 덜 마른 것.
- 너무 두꺼운 바닥·덩어리(소품 속 꽉 찬 것): 안쪽 수분이 늦게 빠짐. 원데이 소품에서 자주. → 두꺼운 건 바닥에 구멍 뚫거나 속 파내기.
- 공기 방울: 흙 치대기 덜 해서 안에 공기 → 부풂·터짐.

[건조·초벌 단계 금 — 이음새]
- 손잡이 이음새, 판성형 이음새, 바닥-벽 연결부에 금. 슬립·긁기 부족이 원인.
- 흙 두 종류 섞어 붙인 작품(백자토+분청토 등)은 수축률 차이로 이음새 갈라짐.
- 접시 바닥 S자 금: 물레에서 바닥 압축 안 함.

[재벌 때 — 유약·온도 문제]
- 유약 흘러내려 가마 선반(받침판)에 붙음 → 떼다가 굽 깨짐. 천목유 OG-I41, 재유 OG-A51, LF-142 Floating Blue, LF-226 Honey Flux, 결정유 BG-X51이 단골.
  → 굽 1cm 남기기, 흐르는 유약은 받침 필수. 수입 LF 유약은 Cone 5/6(≈1186~1222℃)이라 우리 1240℃보다 낮아서 더 흐름 → 가마 아랫단 + 받침.
- 흙 소성 온도 초과: 적토 ST-R810(1240℃에서 휨·부풂), 흑토 ST-K710(1250℃ 이상 부풂). 가마 윗단이 더 뜨거움 → 이런 흙은 아랫단.
- 라쿠토 ST-RK910은 1180℃까지 → 우리 재벌에 들어가면 녹아 무너짐. 반입 금지.
- 유약 너무 두꺼움: 흘러내림 + 기포·벗겨짐(크롤).
- 급랭: 다 식기 전에 가마 문 열면 "딱" 하고 금 감(냉각 균열). 조급해서 문 열지 말 것! 대표님만 문 엶.
- 작품끼리 닿음: 유약 붙어서 둘 다 상함. 간격 1cm 이상.

[가마 자체 문제]
- 열선 이상·온도 컨트롤러 오류로 온도 오버 → 2025.07 한 번 있었음(아래 사례).
- 받침판 금 간 것 계속 쓰면 소성 중 받침판이 깨지며 작품 떨어짐.

2. 발견했을 때 강사가 할 일
==================================================
1) 가마 꺼낸 작품 확인할 때 이상 있으면 바로 따로 빼둠(다른 완성품과 섞지 않기).
2) 사진: 작품 전체 / 깨진 부분 가까이 / 바닥 이니셜 / 가마 안 위치(가능하면 꺼내기 전).
3) 작품 목록에서 누구 건지, 원데이·정규반인지, 유약·흙 코드 확인.
4) 원인 추정 메모(덜 마름? 유약 흐름? 이음새?) → 대표님께 사진과 함께 공유.

5) 수강생 연락은 대표님 확인 후. 보통 류쌤이나 대표님이 DM. 강사가 할 땐 아래 초안 사용.
6) 깨진 작품은 처리 정해질 때까지 버리지 말 것(수강생이 조각이라도 갖고 싶다는 경우 있었음).

3. 수강생에게 알리는 말투 초안 (DM용)
==================================================
공통: 사과 먼저 → 무슨 일인지 짧게 → 사진 → "대표님이 직접 연락드려 상의" → 보상 내용은 말하지 않음.
"원래 그래요", "흔한 일이에요" 같은 말 금지(수강생 탓처럼 들림). 원인을 수강생 실수로 단정하지 말 것.

[초안 1 — 기본]
안녕하세요 OO님, 흙과불 도자기공방입니다.
지난 O월 O일 수업에서 만드신 머그가 가마에서 굽는 과정 중에 금이 가서 연락드렸어요. 정말 죄송합니다.
사진 함께 보내드려요. 어떻게 해드리면 좋을지 대표님이 직접 연락드려서 상의드리려고 해요. 편하신 연락 시간 알려주시면 맞춰서 연락드릴게요.

[초안 2 — 완전히 깨졌을 때]
OO님 안녕하세요, 흙과불입니다.
너무 죄송한 소식을 전해드리게 됐어요. 만드신 작품이 가마 안에서 깨져버렸어요. 소성 중에 생긴 일이라 저희도 많이 아쉽습니다.
사진 보내드리고, 대표님이 오늘 중으로 따로 연락드려 앞으로 어떻게 할지 말씀 나누려고 해요. 깨진 조각은 버리지 않고 보관하고 있으니 혹시 원하시면 말씀 주세요.

[초안 3 — 금은 갔는데 쓸 수는 있는 것(장식용으로)]
OO님 안녕하세요, 흙과불 도자기공방입니다.
작품이 완성됐는데, 굽는 과정에서 바닥 쪽에 가는 금이 생겼어요. 사진 확인 부탁드려요.
금 간 부분 때문에 물이 샐 수 있어서 컵으로 쓰시긴 어렵고, 연필꽂이나 장식으로는 괜찮아요. 받아보실지, 다른 방법이 좋으실지 대표님이 연락드려서 함께 정하려고 해요.
→ "장식으로는 괜찮다"까지만. 재제작 해준다는 말 X.

[초안 4 — 여러 명 작품이 같이 상했을 때(가마 사고)]
안녕하세요 OO님, 흙과불 도자기공방입니다.
이번 가마 소성 중에 가마 온도 문제가 생겨서 OO님 작품을 포함해 여러 작품이 손상됐어요. 저희 쪽 문제라 정말 죄송합니다.
사진 함께 보내드리고, 대표님이 한 분씩 직접 연락드려 상의드리겠습니다.

[초안 5 — 영어]
Hello, this is Heukgwabul Pottery Studio. We are very sorry, but your piece cracked in the kiln during firing. Here are the photos. Our owner will contact you soon to discuss what we can do. Thank you for understanding.
(공방 영문 표기는 류쌤이 쓰는 것 따를 것)

(류쌤 의견: 사진 없이 글로만 보내면 수강생이 더 걱정함. 사진 꼭 같이. 2025.05)
(대표님: 처음 연락에서 "다시 만들어드릴게요"라고 하면 나중에 못 지키는 경우가 생김. 첫 연락엔 상의하자고만. 2025.08)

5. 메모 — 기준 정해야 함
==================================================
- 처리 기준은 아직 정해지지 않음. 매번 대표님과 상의.
- 2025.07 사고 이후 대표님이 "기준표 만들자"고 했는데 아직 안 됨. 논의 나왔던 것들:
  · 원데이/정규반 나눠서 할지
  · 공방 원인 vs 수강생 원인 나눠서 할지 (근데 원인 구분이 애매한 경우가 많음)
  · 재방문 못 하는 분은 어떻게 할지
  · 할인 제안을 할지 말지, 하면 몇 %인지
  → 전부 결론 없음. (2026.03 대표님: 연말 전에 한 번 정리하자)
- 그 전까지 강사가 지킬 것:
  1) 보상 내용 먼저 말하지 않기
  2) 사진 + 작품 정보 + 원인 추정을 대표님께 빠르게
  3) 사례표(4번)에 한 줄 추가 — 날짜/작품/상황/대처/비고
  4) 수강생 반응도 기록(수락/거절/서운해함)
- 예방이 제일 나음:
  □ 건조 충분히(볼에 대서 차가우면 X)
  □ 두꺼운 건 속 파기
  □ 이음새 긁기+슬립
  □ 흐르는 유약 굽 1cm + 받침 + 아랫단
  □ 적토·흑토 개인 흙은 미리 경고하고 작품 목록에 "경고함" 기록
  □ OG-C21(환원용 청자유) 꺼내놓지 않기 → 2025.01부터 창고 위 칸으로 옮겨둠
  □ 가마 문은 대표님만, 다 식고 나서

2) 나: 작품 목록에서 9점 주인 확인, 원데이/정규반 구분, 연락처 정리

4) 대표님: 이틀에 걸쳐 한 분씩 통화

→ 이 사고 이후 대표님이 "기준표 만들자" 말씀하심. 아직 안 됨(5번 메모).

7. 원인별로 대표님께 공유할 때 같이 적을 것
==================================================
대표님이 상의하실 때 필요한 정보. 사진 보낼 때 같이 정리해서 보낼 것.
| 항목 | 적을 내용 |
| 수강생 | 이름(성+이니셜), 원데이/정규반, 수업 날짜 |
| 작품 | 종류, 흙 코드, 유약 코드, 선반 위치 이력 |
| 단계 | 건조 중 / 초벌 / 재벌 / 꺼낼 때 |
| 상태 | 금(길이·위치), 깨짐, 휨, 유약 붙음 |
| 추정 원인 | 덜 마름 / 두께 / 이음새 / 유약 흐름 / 흙 온도 초과 / 가마 |
| 사전 안내 | 작품 목록에 "경고함" "장식용 안내함" 기록 있는지 |
| 수강생 상황 | 재방문 가능 여부(알면), 선물용이었는지 등 |
- "사전 안내 기록" 칸이 중요함. 2026.08 적토 건처럼 미리 경고한 기록 있으면 대표님 상의가 훨씬 수월했음.
- 원인 추정은 "추정"이라고 적을 것. 단정 X.
(류쌤 의견: 원데이 수강생은 선물용으로 만든 경우가 많아서 날짜 맞춰야 하는 사정이 있는 경우가 있음. 처음 연락할 때 "혹시 필요한 날짜가 있으셨는지"도 물어보면 대표님이 상의하기 편함. 2025.11)

==================================================
8. 노쇼·대기자·단체와 엮일 때
==================================================
- 재제작하려고 재방문 날짜 잡았는데 안 오심(노쇼) → 노쇼 처리 기준 자체가 없음. 대표님께.
- 재방문할 수업 자리가 꽉 참 → 대기자 운영 방식 정해진 거 없음. 빈자리 생기면 류쌤이 연락하는 정도.
- 단체 클래스 작품이 가마에서 깨짐 → 단체 견적 기준도 없고 파손 기준도 없음. 담당자(회사 쪽)한테 연락할지 개인한테 할지부터 대표님 확인.
→ 셋 다 "정해진 기준 없음 / 매번 대표님과 상의". 강사가 임의로 정하지 말 것.

==================================================
9. 수강생 반응별 메모 (다음 연락 때 참고)
==================================================
- "괜찮아요, 그냥 주세요" → 그대로 수령. 그래도 대표님께 보고하고 사례표 기록. 장식용으로만 쓰라는 안내(금 간 것)는 꼭.
- "다시 만들고 싶어요" → 재제작을 할지는 대표님 결정. 강사는 "대표님께 전달드릴게요"까지.
- "돈 돌려주세요" → 환불 여부·금액 대표님 결정. 원데이 취소 규칙(3일 전 전액/이후 50%)은 예약 취소 규칙이지 파손 규칙이 아님 → 그걸 근거로 답하지 말 것!
- 화를 내심 → 변명·원인 설명 길게 하지 말고 사과 + 대표님 연결. 원인 얘기는 대표님 통화 때.
- 연락 안 됨 → 3일 간격으로 2번 더 DM. 그래도 안 되면 대표님께. 보관은 완성 후 60일 규칙 따르되, 파손품 처분은 대표님 판단(2025.07 건처럼 계속 보관 중인 것도 있음).
(2026.10 추가) 사례표 날짜 순서 지키기. 같은 날 여러 건이면 한 줄에 몰지 말고 한 건씩.
