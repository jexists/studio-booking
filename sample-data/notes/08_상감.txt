※ 정규반 심화. 원데이에서는 시간상 거의 안 함(원데이로 하면 이름 이니셜 정도만).
※ 인화(07 분청 노트)랑 원리 비슷함. 인화는 도장으로 홈, 상감은 칼로 파서 홈.

1. 상감이 뭔지
- 흙 표면에 무늬를 파내고(음각), 그 홈에 다른 색 흙(화장토)을 메운 다음, 표면을 긁어내서 홈에만 색이 남게 하는 기법.
- 수강생 설명: "그릇에 홈을 파서 색 흙으로 메꾸는 거예요. 상감청자 아시죠? 그 학 무늬 같은 거."
- 단, 상감청자처럼 푸른 바탕은 우리 가마에서 환원이 안 되니까 그 색 그대로는 안 나온다고 미리 말할 것 → 공방에선 청자토 ST-C410 + 산화청자유 OG-C22로 "산화청자 상감"까지 가능. 연한 청록. 07 노트의 OG-C21 사건 참고.

2. 흙과 화장토 조합 (공방에서 실제 해본 것)
| 바탕 흙 | 메우는 것 | 유약 | 느낌 |
| 분청토 ST-B310 | 백토 화장토 ST-SL120 | 분청 투명유 OG-P31 | 회흑 바탕에 흰 선. 제일 잘 보임 |
| 청자토 ST-C410 | 백토 ST-SL120 + 흑토 ST-K710 슬립 | 산화청자유 OG-C22 | 흑백 상감, 산화청자 느낌 |
| 백자토 ST-W110 | 색 화장토 세트 ST-SL130(5색) | 투명유(유광) OG-T01 | 흰 바탕 컬러 상감. 젊은 수강생 선호 |
| 백자토 ST-W110 | 흑토 ST-K710 슬립 | OG-T01 또는 OG-T02 | 흑선 상감, 깔끔 |
| 흑토 ST-K710 | 백토 ST-SL120 | OG-T01 | 대비 최강. 단 흑토 1250℃ 이상 부풂 주의 |
- 색 화장토 세트 ST-SL130은 새터도재 5색 세트(상감·그림용, 1220~1260℃). 2kg 통 아님, 작은 통 5개. 색 이름은 통에 적힌 대로 부를 것.
- 흑토 슬립은 따로 파는 거 없어서 흑토 ST-K710 트리밍을 물에 풀어 체로 거른 걸 씀. 통에 "흑토 슬립(상감용)" 라벨.
- 바탕 흙과 메우는 흙의 수축률이 비슷해야 함. 새터 자료집 참고하면 백자토 13%, 분청토 12%, 청자토 12.5%, 흑토 11%. 차이가 2% 넘어가면 메운 선이 벌어지거나 들뜰 수 있음. 백자토 바탕 + 흑토 상감은 차이 2%라 아슬아슬함 → 선을 가늘게(2mm 이하) 할 것.

3. 준비물
- 상감용 칼: 루프툴 소(극소), 조각도(V형·U형), 철필, 대나무 칼
- 밑그림용 연필(흑연), 트레이싱지(도안 옮길 때)
- 화장토: ST-SL120 / ST-SL130 / 흑토 슬립
- 작은 붓(세필·평붓 1cm), 스포이드(가는 선 메울 때 편함)
- 금속 헤라(리브), 스크래퍼(긁어내기용)
- 비닐, 분무기 — 작업 시간이 길어서 마르는 거 계속 관리
- 견본: 선반 E-4 타일 박스에 상감 견본 8개

4. 순서
① 성형 후 가죽 상태(손톱 자국 살짝 남는 정도)까지 말림. 너무 젖으면 파낸 선이 뭉개지고, 너무 마르면 메운 흙이 안 붙음.
② 연필 밑그림. 도안 있으면 트레이싱지 대고 볼펜 끝으로 눌러서 자국 내기(볼펜 잉크가 흙에 직접 닿으면 안 됨).
③ 선 파기. 깊이 1~1.5mm, 폭 1~3mm. 옆면이 5mm면 깊이 1.5mm 넘기지 않기.
④ 파낸 부스러기 붓으로 살짝 털기(완전히 다 털 필요는 없음, 메우면 덮임).
⑤ 화장토 메우기: 붓으로 홈보다 넉넉히, 두툼하게 올림. 한 번 마르면 꺼지니까 2~3번 덧바름. 홈 안에 공기 안 들어가게 붓 끝으로 톡톡.
⑥ 반쯤 마를 때까지 비닐 덮어 기다림(30분~1시간, 계절 따라 다름). 화장토랑 바탕 흙이 비슷한 굳기가 될 때.
----- p.38 -----
⑦ 금속 헤라로 표면 긁어내기. 한 방향으로, 얇게 여러 번. 선이 드러나기 시작하면 멈추고 확인.
⑧ 마무리는 완전 건조 후 고운 스펀지(살짝 젖은)로 표면 정리. 단 너무 문지르면 선 번짐.
⑨ 건조 → 초벌 → 시유 → 재벌.

5. 수강생이 자주 하는 실수
- 너무 마른 흙에 상감 → 메운 흙이 다 마르고 나서 갈라지고, 초벌 후 툭툭 떨어짐. 제일 많음.
- 너무 일찍 긁어냄 → 화장토가 번져서 바탕까지 하얗게 얼룩. "기다리기"가 핵심이라고 계속 말함.
- 홈을 얕게 팜 → 긁어낼 때 선까지 다 날아감.
- 홈을 너무 깊게 → 옆면 뚫림, 또는 건조 때 그 선 따라 금.
- 화장토 한 번만 바름 → 마르면서 꺼져서 홈 안이 비어 있음. 긁어내면 선이 끊겨 보임.
- 손으로 문질러 정리 → 손의 기름·물기로 번짐.
- 색 화장토 여러 색 섞어 씀 → 붓 안 빨고 다른 색 찍어서 탁해짐. 색마다 붓 따로.

6. 강사 체크포인트
□ 바탕 흙과 메울 흙 조합이 위 표 안에 있는지. 표 밖 조합이면 테스트 타일부터.
□ 흙 상태(가죽 상태) 확인하고 파기 시작 허락
□ 홈 깊이 — 수강생 첫 선은 같이 보면서 팜
□ 화장토 2~3회 덧바름 확인
□ 긁어내기 시작 시점은 강사가 판단. 수강생은 늘 너무 빨리 긁으려 함
□ 수업 끝날 때 비닐 + 선반 번호 기록. 상감 작품은 건조 천천히(11 건조 노트) — 바로 선풍기 금지
□ 작품 목록에 "상감/바탕흙/메운흙/유약 코드" 기록

7. 유약 고를 때
- 상감 위에는 투명 계열만. 불투명(OG-N16, OG-M61, LF-112 등) 덮으면 상감이 안 보임.
- 백자토 바탕 컬러 상감: 투명유(유광) OG-T01이 제일 선명. 무광 원하면 OG-T02, 단 무광은 색이 약간 흐려짐.
- 분청토 바탕: 분청 투명유 OG-P31.
- 청자토 바탕: 산화청자유 OG-C22. 두껍게 바르면 상감 선이 흐려지니 표준 두께로. OG-C21(환원용) 통이랑 절대 헷갈리지 말 것.
- LF-138 Celadon Mist도 청자 느낌 상감에 써봤는데, 1240℃에서 흘러서 선 윗부분이 늘어지듯 번짐. 상감에는 비추(2025.12 테스트).
- 식기 여부는 위 유약 모두 온결 카탈로그상 식기 적합. 단 공급처 자료에서 식기 적합 판정은 "표준 시유 두께 + 권장 온도로 소성했을 때"의 결과임. 두껍게 바르거나 온도가 낮으면 결과가 달라질 수 있음.
- 상감 선이 유약 밖으로 드러나거나 들뜬 곳이 있으면 그 부분은 식기 안쪽(음식 닿는 면)에 두지 말 것. 바깥면 장식으로.

8. 실제 수업 사례
- 2024.10 목요일반 6명 첫 상감 수업. 백자토 + 색 화장토 ST-SL130으로 작은 접시. 6명 중 4명이 긁어내기를 너무 빨리 해서 색 번짐. 2명은 너무 늦게(완전 건조 후) 긁어서 가루 날리고 선 가장자리 깨짐. 다음 기수부터 긁어내기 시작은 무조건 강사가 손으로 만져보고 "지금" 해주기로 함.
- 2025.03 토요일반 수강생(정규 3기째) 분청토 머그에 백토 상감 학 무늬 → 이게 공방 인스타 상감 대표 사진. 선 폭 2mm, 깊이 1.2mm, 화장토 3회. 기준 삼을 것.
- 2025.06 흑토 ST-K710 바탕 + 백토 상감 컵 3개 중 1개가 재벌 후 바닥 부풂. 흑토 권장 1200~1240℃인데 가마 윗단 열선 가까운 자리에 들어가서 국부적으로 온도가 더 올라간 듯. 흑토 작품은 가마 중간~아랫단에 놓기로 함 → 10 가마 노트 재임 부분.

- 2026.01 청자토 + 흑백 상감 + OG-C22 화병. 연한 청록 바탕에 흑백 선 잘 나옴. 수강생 만족도 높음. "산화청자 상감"으로 정규반 심화 메뉴에 올림(대표님 OK).
- (2026.08 추가) 색 화장토 ST-SL130 중 한 색이 소성 후 거의 안 보이게 날아감. 통 바닥 가라앉은 안료를 안 저은 게 원인 같음. 상감 전 색마다 1분 이상 저을 것.

9. 원데이에서 상감 맛보기
- 원데이 핸드빌딩 머그·접시에 이름 이니셜이나 간단한 선 하나만 상감으로 넣어줌. 시간 15분 이내.
- 흙이 성형 직후라 너무 젖어 있음 → 선만 파놓고, 메우기·긁어내기는 강사가 다음 날 대신 함. 수강생한테 그렇게 안내.
- 작품 목록에 "상감 마무리 필요" 메모 꼭 남기기. 빠뜨리면 그냥 초벌로 가버림(2025.11 실제로 1건, 파놓은 홈이 빈 채로 완성됨. 수강생은 오히려 좋아했지만 운이 좋았던 것).

10. 메모
- (류쌤 의견: 상감 수업 공지할 때 "시간이 오래 걸리는 기법이라 1회에 작은 작품 1개"라고 써두면 기대치 조절됨)
- 도안 파일은 공방 공용 폴더 "상감 도안" 안에 있음(학·구름·당초·물고기·꽃 5종). 트레이싱지 출력해서 씀.
- 상감은 사진에서 잘 안 보임. 완성 사진은 측광으로 찍으라고 류쌤한테 전달.

11. 흑백 상감 순서 (청자토 바탕일 때)
- 흑과 백을 한 번에 메우면 색이 섞임. 반드시 한 색씩.
① 흑선부터 파고 → 흑토 슬립 메우기 → 반건조 → 긁어내기
② 그다음 백선 파고 → 백토 ST-SL120 메우기 → 반건조 → 긁어내기
③ 흑을 먼저 하는 이유: 흑 부스러기가 백선 위에 묻으면 회색으로 탁해지는데, 반대로 백 부스러기가 흑선에 묻는 건 긁어낼 때 잘 떨어짐.
- 학 무늬면 몸통·날개는 백, 부리·다리·눈은 흑. 구름은 백 테두리 안에 흑 점.
- 두 번 작업하니까 시간 2배. 정규반이면 2회 수업으로 나눠서, 사이에 비닐 보관 철저히.

12. 시간·크기 기준
| 작품 | 상감 면적 | 소요 시간(수강생 기준) | 비고 |
| 이니셜(원데이) | 2~3cm | 10~15분 | 메우기·긁기는 강사 |
| 작은 접시 12cm | 테두리 선 + 무늬 1개 | 1시간 30분 | 정규반 1회 |
| 머그 | 몸통 한 바퀴 띠 | 2시간+ | 손잡이 붙이기 전에 상감 |
| 화병 20cm | 학 2마리 + 구름 | 2회 수업 | 흑백이면 3회 |
- 머그는 손잡이 붙이고 상감하면 손잡이 근처 작업이 안 됨. 순서: 성형 → 굽 → 상감 → 손잡이.
- 무늬 크기는 완성 때 수축(백자토 13%)을 생각해서 원하는 크기보다 조금 크게. 선 폭 1mm는 완성 때 거의 안 보임 → 최소 1.5mm.

13. 건조 주의 (상감 작품 전용)
- 바탕 흙과 메운 화장토가 마르는 속도가 다름. 화장토가 먼저 마르면 선 따라 미세한 금.
- 상감 끝난 작품은 하루 비닐 → 이틀째 비닐 살짝 열기 → 사흘째부터 건조 선반. 총 건조 10~14일 잡을 것. 11 건조 노트 기본보다 길게.
- 선풍기·난방 앞 절대 금지. 선반 B-2(난방 앞) 금지는 상감 작품에 특히 중요.
- 초벌 전 최종 확인: 선 따라 금이 보이면 초벌 전에 같은 화장토로 살짝 메워볼 수 있는데, 성공률 반 정도. 수강생한테 미리 말할 것.

15. 자주 받는 질문
Q. 상감청자 색 나와요? → 환원소성이 필요해서 공방 가마로는 안 나옴. 청자토 + 산화청자유 OG-C22로 연한 청록까지만 가능. 사진 견본 보여줄 것.
Q. 컬러로 하고 싶어요. → 백자토 + 색 화장토 ST-SL130 + 투명유 OG-T01. 다만 화장토 색은 소성 후 생각보다 연하게 나옴. 견본 타일 꼭 보여주기.
Q. 상감한 컵으로 커피 마셔도 돼요? → 유약이 식기 적합이면 일반적으로 사용 가능. 단 표준 시유 두께 + 권장 온도로 소성했을 때 결과라는 점, 그리고 상감 선이 들뜨거나 금 간 곳이 입술·음식 닿는 면에 있으면 쓰지 말라고 안내.
Q. 언더글레이즈로 그리면 안 돼요? → 그건 그림(BG-U20)이고 상감은 흙 자체에 색을 넣는 것. 느낌이 다름. 시간이 없으면 BG-U20 그림이 훨씬 빠르다고 대안 제시.

16. 수업 준비 순서 (상감 수업 있는 날, 수업 1시간 전)
① 화장토 통 꺼내서 젓기: ST-SL120은 바닥까지 5분, ST-SL130은 색마다 1분 이상. 흑토 슬립은 체로 한 번 더 거름(덩어리 있으면 선 메울 때 걸림).
② 작은 종지에 색별로 덜어두기. 원통에서 직접 찍어 쓰면 통이 오염됨. 종지에 남은 건 버림(다시 붓지 말 것).
③ 수강생 작품 비닐 벗기고 가죽 상태 확인. 너무 말랐으면 분무 + 비닐 30분. 너무 젖었으면 선풍기 약풍 20분(상감 전에는 괜찮음, 상감 후엔 금지).
④ 도안 트레이싱지 출력, 연필, 조각도 세트 6벌 테이블에 깔기.
⑤ 견본 타일 박스(E-4) 테이블 가운데.
⑥ 작품 목록 출력본에 오늘 상감 작품 표시 칸 만들기.

17. 강사 연습 과제 (새 강사)
- 백자토 타일 10×10cm 5장에 같은 무늬(구름 하나)를 ST-SL120, ST-SL130 2색, 흑토 슬립으로 각각 상감 → 투명유 OG-T01 → 재벌. 긁어내기 타이밍 감 익히는 게 목적.
- 분청토 타일 2장에 백토 상감 + OG-P31. 07 분청 노트의 인화와 비교해볼 것.
- 결과 타일은 E-4 견본 박스에 추가하고 뒷면에 날짜·흙·화장토·유약 코드 적기. 견본 박스는 공방 자산이라 함부로 빼지 말 것(대표님).
