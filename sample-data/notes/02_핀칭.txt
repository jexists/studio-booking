02 핀칭 (손으로 눌러 빚기)
작성: 권태민 / 최초 작성 2024.03 / 최종 수정 2026.07

----- p.8 -----

핀칭은 흙 공에 엄지를 넣고 엄지·검지로 눌러 가며 벽을 얇게 펴는 방법. 도구가 거의 필요 없고 흙을 손으로 처음 느껴 보기에 제일 좋음. 원데이 핸드빌딩에서 찻잔·종지·작은 볼·인센스 홀더 같은 소품 고른 사람은 거의 핀칭으로 함. 정규반 핸드빌딩반 1주차 첫 30분도 핀칭으로 손 풀게 함.

■ 잘 맞는 흙

- 백자토(일반) ST-W110 — 기본. 표면이 매끈해서 손자국이 예쁘게 남음. 유약 색도 정직하게 나옴.
- 핸드빌딩 샤모트토 ST-H620 — 두껍게 투박한 느낌 원할 때. 샤모트가 있어서 잘 안 갈라짐. 대신 손끝으로 매끈하게 다듬기는 어려움.
- 산청토 ST-S510 — 거친 질감 찻잔에 좋음. 주의! 찻잔·종지처럼 입 대거나 음식 닿는 건 안쪽 전부 시유 필수(흡수율 5~9%). 바깥쪽은 무유로 둬도 됨.
- 분청토 ST-B310 — 정규반에서 핀칭 후 화장토 바르기 연습할 때.
- 조합토 ST-M610 — 물레용이지만 핀칭에도 잘 됨. 물레 원데이 끝나고 남은 흙으로 작은 종지 하나 더 만들게 해 줄 때 씀.

■ 수업 준비물 (원데이 8명 기준)

- 흙: 1인 1kg 지급. 찻잔 하나에 약 250~300g, 작은 볼(지름 12cm 정도) 400~450g. 보통 찻잔 2개나 찻잔 1개 + 종지 1개 정도 만듦.
- 도구 세트(자리마다): 나무 헤라 1, 철 헤라(리브) 1, 바늘 1, 스펀지 1, 물그릇 1, 이름 쓸 꼬챙이
- 작은 원형 석고판 또는 판자(작품 올려 두는 용) 1인 1장
- 두께 확인용 바늘 — 꼭 있어야 함
- 유약 색 후보(색 견본 타일 붙인 판): 미색 유광유 OG-N16, 투명유(유광) OG-T01, 매트백유 OG-M61, 하늘유 OG-B81, 산화청자 OG-C22, 라크필드 LF-125 Oatmeal Speckle, LF-138 Celadon Mist. 찻잔은 미색유·오트밀이 제일 인기.
→ 크랙유(BG-K31)는 색견본판에서 뺐음. 찻잔에 하고 싶다는 분이 꼭 나오는데 빙렬 틈에 찻물이 끼어서 식기 비권장. 장식 소품에만.

■ 기본 순서

1. 흙 공 만들기 — 손바닥 사이에서 굴려 금 간 데 없는 매끈한 공. 표면에 주름이나 금이 있으면 나중에 거기서 갈라짐.
2. 엄지 넣기 — 공 가운데에 엄지를 바닥에서 약 1cm 남기고 넣음. "엄지 한 마디 반 정도" 라고 말함. 바닥을 너무 얇게 뚫는 사람 꼭 나옴.
3. 누르며 돌리기 — 엄지는 안, 나머지 손가락은 밖. 아래쪽부터 살짝 누르고 공을 조금씩 돌림. 한 바퀴 돌 때마다 조금씩 위로.
4. 벽 펴기 — 3~4바퀴에 걸쳐 천천히. 한 번에 얇게 하려고 하면 무조건 찢어짐.
5. 입구 정리 — 입구가 갈라지면 손가락에 물 아주 조금 묻혀 쓰다듬기. 갈라진 데가 깊으면 그냥 바늘로 잘라 내고 수평 맞추기.
6. 바닥 다듬기 — 테이블에 살짝 쳐서 바닥 평평하게. 굽 원하면 꾸덕해진 뒤 따로 붙이거나 깎음(원데이는 강사가).
7. 표면 마무리 — 철 헤라로 안쪽 매끈하게, 바깥 손자국은 남길지 지울지 수강생이 선택.
8. 이름·날짜 — 바닥에 꼬챙이로 이니셜. 작품 목록과 맞추려면 꼭 필요함.

■ 두께 기준

- 찻잔 벽: 4~5mm. 바닥: 6~7mm.
- 작은 볼: 벽 5~6mm, 바닥 7~8mm.
- 바늘을 벽에 수직으로 찔러 보고 들어간 깊이 보면 됨. 수강생한테도 바늘 쓰는 법 알려 주면 스스로 확인함.
- 너무 두꺼우면(1cm 넘으면) 무겁고 초벌 때 속까지 안 말라서 터질 수 있음. 바닥이 두꺼운 핀칭 작품은 바닥 안쪽을 숟가락처럼 파내게 하거나, 강사가 꾸덕할 때 밑에서 깎아 줌.
- 손이 무거운 분은 계속 두꺼워지고, 섬세한 분은 계속 얇아짐. 두꺼운 사람한테는 "한 바퀴 더", 얇은 사람한테는 "이제 그만, 입구만 정리" 라고 말해 줄 것.

■ 수강생이 자주 하는 실수

- 엄지로 바닥 뚫음 → 구멍 작으면 흙 작은 조각 꾹 눌러 메우고 바깥에서 문질러 이음. 크면 다시 공으로 뭉쳐 처음부터(흙이 질어졌으면 새 흙으로).
- 물 너무 많이 씀 → 표면이 질척해지고 벽이 주저앉음. 핀칭은 물 거의 안 씀. 물그릇은 입구 갈라질 때만. "손에 물 묻히지 마세요, 스펀지 꽉 짜서 살짝만."
- 한쪽만 계속 누름 → 벽 두께가 한쪽만 얇아지고 기울어짐. 돌리는 방향을 일정하게.
- 입구를 너무 벌려서 접시처럼 됨 → 찻잔 원하는데 납작해짐. 입구 쪽은 손가락으로 살짝 오므리듯 감싸 주면서 올리기.
- 손잡이 붙이고 싶어 함 → 핀칭 찻잔에 손잡이 붙이는 건 원데이 시간 안에 어려움. 붙이더라도 바로 붙이면 떨어짐(꾸덕해야 함). 원데이에서는 "손잡이 없는 찻잔"으로 유도. 꼭 원하면 머그로 바꾸게 하고 04번 판성형 방법으로.
- 두 개 만들다 시간 부족 → 첫 번째 거에 30분 넘게 쓰는 분 많음. 50분쯤에 "두 번째 시작하세요" 꼭 말할 것.
- 손자국 다 지우려고 계속 문지름 → 흙이 말라서 표면에 실금. 손자국도 핀칭의 매력이라고 말해 주면 대부분 멈춤.

■ 수업에서 있었던 일

- 2024.06 원데이: 찻잔 바닥을 3mm 정도로 얇게 만든 분이 있었음. 건조하다 바닥에 S자 금. 다시 만들 시간이 없어서 그대로 초벌 → 재벌 후 물 새서 결국 연필꽂이로 쓰시라고 안내. → 이후로 수업 마치기 전에 모든 작품 바닥 두께를 바늘로 한 번씩 찔러 봄.
- 2025.02 정규반: 수강생이 핀칭 볼에 크랙유 BG-K31을 바르고 싶다고 해서 "장식용이면 OK, 밥그릇이면 비권장"이라고 했는데 나중에 보니 밥그릇으로 쓰고 있었음. → 빙렬 틈 오염 문제를 말로만 하지 말고 빛가람 자료 보여 주면서 설명. 작품 목록에도 "장식용" 표시(류쌤이 적어 줌).
- 2025.09 원데이: 커플 두 분이 서로 찻잔 하나씩 만들어 주기로 해서 이름을 상대방 이니셜로 씀. 작품 목록에는 본인 이름으로 들어가서 수령 때 헷갈림. → 이니셜 쓸 때 "본인 이니셜 + 작은 표시"로 통일하고, 다르게 쓰는 경우 강사가 목록 비고에 적어 둘 것.
- 2026.05 원데이: 인센스 홀더 만들면서 바닥에 구멍 낸 분. 핀칭 작품에 구멍 뚫는 건 괜찮은데 너무 작으면(지름 3mm) 13% 수축 후 향 꽂이가 안 들어감. → 구멍은 젓가락 굵기 정도로 넉넉히.

■ 강사 체크포인트

- 시범은 처음 5분 안에 끝낼 것. 핀칭은 손으로 해 봐야 아는 거라 설명이 길면 오히려 안 됨.
- 15분 지나서 한 바퀴 돌며 바닥 두께, 입구 갈라짐, 벽 기울어짐 확인. 손을 잡아서 누르는 힘을 직접 느끼게 하는 게 제일 빠름.
- 마무리 전: 바닥 두께 바늘 확인 / 입구 금 없는지 / 이름 썼는지 / 작품 판에 올렸는지.
- 유약 고를 때: 식기로 쓸 건지 먼저 물어보고 식기면 09번 표에서 "적합"인 것만 보여 줌. 산청토면 안쪽 전부 시유 표시 꼭 남길 것(시유 때 다른 강사가 봐도 알게).
- 핀칭 작품은 벽 두께가 고르지 않아서 건조 때 금이 잘 감. 건조 선반 올릴 때 비닐 살짝 덮어서 첫 2~3일 천천히 말리기(11번 참고).
- 다 끝나고 테이블에 흙 덩어리 떨어진 것 정리. 핀칭은 손에 흙이 많이 남아서 손 씻는 줄이 길어짐 → 개수대 침전 통 먼저 쓰라고 안내.

(류쌤 의견: 원데이 문의에서 "찻잔 만들어서 전자레인지에 데워도 되나요?" 질문이 많음. 미리 말해 주면 좋겠음.) → 공방 기본 유약(OG-T01, OG-N16, OG-M61, OG-B81, OG-C22, LF-125, LF-138)은 전자레인지 가능. 금채(BG-G61)·라스터(BG-P71)는 불가(스파크). 원데이에서는 금채·라스터 안 쓰니까 "기본 유약은 다 돼요"라고 해도 됨. 정규반에서 금채 했으면 반드시 따로 안내.

■ 원데이 핀칭 시간 배분 (2시간 수업 중)

- 0:00~0:10 인사, 앞치마, 오늘 일정 설명(완성까지 3~4주, 가마 사정에 따라 더 걸릴 수 있음 — 날짜 약속 금지)
- 0:10~0:15 흙 만져 보기 + 핀칭 시범
- 0:15~0:50 첫 번째 작품(찻잔 또는 볼)
- 0:50~1:25 두 번째 작품(종지·소품). 첫 번째 작품은 그사이 판 위에서 살짝 굳힘
- 1:25~1:40 표면 마무리, 도장·무늬 넣기, 이름 쓰기
- 1:40~1:55 유약 색 고르기(색견본판 보고 작품마다 1색, 안/밖 다르게는 +1색까지)
- 1:55~2:00 수령 방법 안내(방문 또는 택배 4,000원, 선물 포장 5,000원), 정리
→ 유약 고르는 데 생각보다 오래 걸림. 15분 아래로 줄이면 꼭 밀림. 12번 진행표도 이 기준으로 맞춰 둠.

■ 핀칭 응용 (정규반·손 빠른 원데이 수강생)

1) 굽 붙이기 — 꾸덕해진 찻잔 바닥에 흙가래를 링으로 붙여 굽 만들기. 붙이는 면은 바늘로 긁고(스코어링) 흙물(슬립) 발라서. 원데이에서는 꾸덕해질 시간이 없어서 강사가 다음날 대신 붙임. 강사 업무 늘어나니까 원데이에선 웬만하면 바닥 평굽으로.
2) 두 개 맞붙이기 — 핀칭 볼 두 개를 입구끼리 붙여 속 빈 공 만들기. 오브제·저금통·방울. 주의! 속이 막힌 채로 가마 들어가면 공기 팽창으로 터짐. 반드시 바늘로 공기 구멍 하나 이상 뚫을 것. 2024.11 정규반에서 구멍 안 뚫은 저금통이 초벌 때 터져서 옆 작품 두 개까지 깨짐. 그 뒤로 초벌 넣기 전에 대표님이 속 빈 작품은 흔들어 보고 구멍 확인함.
3) 텍스처 — 나뭇잎, 레이스, 도장으로 꾸덕하기 전에 바깥 찍기. 핀칭은 벽이 얇아서 세게 누르면 구멍 남. 손바닥으로 안쪽 받치고 찍기.
4) 주둥이 — 볼 입구를 손가락으로 살짝 접어 따르는 주둥이(편구). 드레싱 볼, 소스 그릇. 원데이에서도 5분이면 됨.
5) 각 잡기 — 다 만든 뒤 꾸덕하기 전에 판자로 네 면을 톡톡 쳐서 사각 느낌. 찻잔보다는 연필꽂이·작은 화분에.

■ 유약 추천 (핀칭 작품 기준, 실제 결과 위주)

- 미색 유광유 OG-N16 — 원데이 찻잔 1순위. 손자국 있는 부분에 유약이 고여서 살짝 진하게 나옴. 예쁨.
- 라크필드 LF-125 Oatmeal Speckle — 점박이가 핀칭 질감이랑 잘 맞음. 대신 Cone 5/6 유약이라 공방 1240℃에서 살짝 흐름. 바닥에서 1cm 위까지 바르지 말 것. 가마 아랫단 + 받침(대표님 담당).
- 산화청자 OG-C22 — 연한 청록. 오목한 데 고이면 진해져서 핀칭 손자국이 잘 드러남.
- 매트백유 OG-M61 — 무광 흰색. 식기 적합이지만 수저 자국 남을 수 있다고 온결 카탈로그에 있음. 찻잔엔 괜찮고 밥그릇은 그 얘기 해 줄 것.
- 하늘유 OG-B81 — 연하늘. 백자토에서 깨끗함.
- 천목유 OG-I41 — 흑갈색. 흘러내리므로 굽에서 1cm 남김. 핀칭 작품은 바닥 쪽이 두꺼워서 유약도 두껍게 먹는 경향 → 붓으로 덧칠 금지.
- 언더글레이즈 BG-U20 + 투명유 OG-T01 — 그림 그리고 싶은 분. 초벌 후 그리는 게 원칙인데 원데이에서는 성형 당일 생흙에 그려도 됨(빛가람 자료상 1000~1250℃ 범위라 문제없음).
→ 산청토 ST-S510 찻잔이면 위 유약 중 하나로 반드시 안쪽 전부 시유. 바깥 무유로 두고 싶다는 분 많은데 그건 OK.

■ 정규반 핸드빌딩 1주차 첫 30분 (핀칭으로 손 풀기)

- 목표는 작품이 아니라 "흙이 손에서 어떻게 변하는지" 보기. 찻잔 하나만.
- 같은 흙 300g으로 각자 만들고, 다 끝나면 바늘로 두께 재서 서로 비교. 제일 고르게 만든 사람 거를 같이 봄.
- 이 찻잔은 나중에 유약 테스트용으로 씀. 정규반 3주차 시유 수업 때 각자 찻잔에 유약 두 가지(안/밖)를 발라 보면서 두께 차이를 직접 봄.
- 정규반 수강생은 손이 금방 익어서 2주차쯤 되면 핀칭으로 꽤 큰 볼(600g)도 만듦. 그때부터는 벽 무너짐 막으려고 중간에 10분씩 굳히는 법 알려 줌.

■ 수업 끝난 뒤 강사가 할 일 (핀칭 작품)

1. 작품 판째로 건조 선반으로. 이름·유약 색 메모지(작품 판 밑에 끼움)를 꼭 같이. 메모지에는 이름 / 수업 날짜 / 흙 코드 / 유약 코드 / 식기 여부 / 수령 방법을 적음.
   예) 김○○ / 2026.06.14 일 11:00 / ST-W110 / 안 OG-N16, 밖 LF-125 / 식기 / 택배
2. 다음날 꾸덕한 상태에서 바닥 확인. 바닥 가장자리 날카로우면 스펀지로 둥글게. 굽 요청 있었으면 이때 붙임.
3. 금 간 작품은 바로 표시. 금이 작으면 꾸덕할 때 흙물로 메워 볼 수 있지만, 백건 이후 금은 거의 못 살림. 수강생 연락은 류쌤한테 부탁(직접 DM 보내지 말 것 — 연락 창구 하나로).
4. 백건 확인 후 초벌 대기 선반으로. 초벌은 대표님이 30점 모이면 돌림.
5. 류쌤 작품 목록에 선반 위치(A-1 ~ E-5) 업데이트됐는지 확인.

■ 핀칭에서 자주 받는 질문 (수업 중)

- "이거 물 새요?" → 바닥·벽에 금 없고 안쪽까지 시유하면 안 샘. 백자토 ST-W110은 흡수율 0.5% 이하라 시유 안 한 바깥도 거의 안 스밈. 산청토는 다름(안쪽 전부 시유).
- "식기세척기 돼요?" → 공방 기본 유약은 대부분 됨. 다만 핀칭 작품은 두께가 고르지 않아서 급격한 온도 변화에 약할 수 있음. 손 설거지 권장이라고 말함. 금채(BG-G61)는 식기세척기 불가.
- "오븐 돼요?" → 온결 카탈로그상 기본 유약은 오븐 가능. 그래도 핀칭 찻잔을 오븐에 넣을 일은 거의 없으니 굳이 권하지 않음. 직화(가스불)는 절대 안 됨.
- "제 거 언제 와요?" → 3~4주, 가마 사정에 따라 더. 완성되면 류쌤이 연락. 완성 후 60일 보관.
