[수업 노트 11] 건조와 갈라짐 (건조 단계·선반 관리·갈라짐 원인과 대처)
작성: 권태민 / 최초 작성 2024.04 / 최종 수정 2026.11
----- p.52 -----

※ 작품 흐름: 성형 → 건조 7~14일 → 초벌 → 시유 → 재벌 → 완성 → 수령. 건조가 제일 눈에 안 띄는데, 가마에서 깨지는 원인 절반이 여기서 생김(10 노트 7번).
※ 건조 선반은 원칙적으로 강사들이 같이 봄. 화·목·토 정규반 강사 + 원데이 강사 모두 수업 끝나면 한 바퀴.

1. 건조 단계 (수강생 설명용)
| 단계 | 상태 | 할 수 있는 것 |
| 젖은 상태 | 성형 직후, 손자국 그대로 남음 | 모양 수정, 화장토(분청), 붙이기 |
| 가죽 상태 | 손톱 자국 살짝, 모양 안 무너짐 | 굽깎기(06), 손잡이, 상감(08), 인화 |
| 반건조 | 색이 밝아지기 시작, 차가움 | 상감 긁어내기, 가벼운 다듬기 |
| 완전 건조(뼈 건조) | 색 완전히 밝아짐, 손등 대도 안 차가움 | 초벌만 가능. 깨지기 쉬움 |
- 확인법: 작품을 손등이나 볼에 살짝 대봄. 차가우면 아직 수분 있음. 미지근하면 건조 끝.
- 색 확인: 백자토 ST-W110은 젖으면 회색, 마르면 흰색. 분청토 ST-B310은 젖으면 거의 검정, 마르면 회색. 바닥까지 색이 같아야 함. 바닥만 진하면 덜 마른 것.

2. 기본 건조 방법
- 성형 직후: 비닐 씌워 하루(작품 크기·두께에 따라 이틀). 수분이 위아래로 고르게 퍼지게.
- 2~3일째: 비닐 살짝 열기(입구 쪽 틈). 손잡이·주둥이·얇은 테두리는 비닐 조각으로 따로 감쌈(먼저 마르니까).
- 4일째~: 비닐 벗기고 건조 선반. 그릇은 뒤집어 놓기(입구 아래로) → 바닥이 마르게. 단 입구가 얇은 건 뒤집으면 찌그러짐, 똑바로 두고 하루에 한 번 돌려줌.
- 판 성형 접시: 석고판이나 나무판 위에. 비닐 바닥에 두면 바닥이 안 마름. 위에 가벼운 판 하나 덮어두면 휨 방지.
- 총 7~14일. 두꺼운 것(바닥 1cm 이상), 겨울, 장마철은 14일 꽉 채움.
- 건조 선반 위치: 작품 선반 A~E 중 A·B단 일부가 건조용. B-2(난방 앞)는 건조 금지(2024.11 사건, 06 노트). 지금 B-2는 유약 대기 선반.
- 선풍기·드라이기로 말리기: 원칙적으로 금지. 급할 때 드라이기는 성형 중 모양 잡을 때만(코일 쌓다가 아래가 무너질 때 등). 건조 단계에선 X.

3. 계절별 메모 (망원동 2층 작업실 기준)
- 봄·가을: 제일 무난. 7~10일.
- 여름(6~8월): 낮엔 빨리 마르는데 장마철엔 2주 넘어도 바닥이 축축. 에어컨 켜면 바람 직접 닿는 쪽만 마름 → 에어컨 바람 방향 위로. 장마철엔 제습기 작업실 가운데에(2025.07부터).
- 겨울(12~2월): 난방 켜면 공기 바짝 마름. 위쪽 선반(따뜻한 공기)은 빨리, 아래쪽은 느리게. 얇은 작품은 아래쪽, 두꺼운 건 위쪽에 두는 식으로 조절. 밤엔 난방 끄니까 온도 차 큼 → 비닐 단계를 하루 더 길게.
- 겨울 아침 첫 수업 강사는 선반 온도계 확인(B단 위에 걸려 있음). 10℃ 아래면 얼 수 있음 → 젖은 작품 얼면 흙 구조 깨짐. 2025.01 한파 때 실제로 원데이 작품 2점 표면이 부슬부슬해짐.

4. 갈라짐(금)의 종류와 원인
(1) 바닥 S자 금
- 바닥 가운데 S자나 일자로 갈라짐. 물레 작품에 많음.
- 원인: 바닥 흙을 덜 다짐(물레 성형 때 바닥 누르기 생략), 바닥 가운데 물 고인 채 방치, 굽 너무 깊게 깎아 바닥 얇아짐.
- 예방: 물레 성형 때 바닥을 손가락·스펀지로 안쪽에서 바깥으로 꾹 누르기(압축). 물은 스펀지로 다 빼기. 06 노트 두께 기준.
----- p.53 -----
(2) 입구 테두리 금
- 입구에서 아래로 짧은 금. 얇은 입구가 먼저 마르면서 수축.
- 예방: 입구 비닐로 감싸기, 뒤집어 말리기 전 하루는 똑바로.
(3) 이음새 금(손잡이·붙인 장식·판 성형 모서리)
- 붙일 때 수분 차이, 긁기·슬립 생략, 이음새 덜 메움.
- 예방: 같은 수분 상태끼리 붙이기, 크로스 긁기 + 슬립 + 문질러 메우기. 붙인 뒤 하루 비닐.
(4) 바닥 가장자리 금(접시)
- 바닥이 선반에 붙어서 수축할 때 못 움직임 → 가장자리에서 갈라짐.
- 예방: 판 위에 신문지 한 장 깔고 말리기. 큰 접시는 중간에 한 번 들어서 위치 바꿔주기.
(5) 화장토·상감 금
- 화장토가 바탕보다 빨리 마르거나, 마른 흙에 바름. 07·08 노트.
(6) 산청토·샤모트토 작품의 거친 금
- 산청토 ST-S510, 핸드빌딩 샤모트토 ST-H620은 알갱이가 커서 갈라짐에는 오히려 강함(수축 10%, 9%). 대신 표면에 잔금이 보이는 경우 있음. 젖은 손으로 문질러 메움.

5. 갈라졌을 때 대처
- 젖은 상태·가죽 상태에서 발견: 금 따라 바늘로 V자 홈을 살짝 파고 → 같은 흙 + 식초 몇 방울 섞은 슬립(또는 종이섬유 섞은 흙, 공방엔 "보수용 흙" 통 있음)으로 메움 → 안팎으로 문지름 → 비닐 덮어 천천히 다시 말림. 성공률 높음.
- 완전 건조에서 발견: 메워도 메운 흙만 다시 수축해서 금이 또 생기는 경우가 많음. 성공률 반 정도. 수강생한테 미리 말할 것.
- 초벌 후 발견: 메울 수 없음(10 노트 10번). 류쌤 통해 수강생에게 연락, 그대로 진행할지 물어봄.
- 완전 건조 작품을 물에 담가 다시 무르게 하는 건 불가 → 흙이 풀려버림. 그 경우엔 재생흙 통으로.
- 금 메우기는 강사가 함. 수강생이 혼자 물 묻혀 문지르다 더 벌어지는 경우 많음.

6. 수강생이 자주 하는 실수
- 성형 끝나고 비닐 안 씌우고 감 → 다음 주에 바짝 마름(특히 정규반). 06 노트처럼 강사가 마지막에 확인.
- 집에 가져가서 말리겠다고 함 → 원칙적으로 불가. 운반 중 파손 + 건조 상태 관리 안 됨.
- 손잡이 붙인 머그를 바로 선반에 → 손잡이 먼저 말라 이음새 금.
- 바닥 물 고인 채로 둠 → S자 금.
- 너무 두껍게 만듦(2cm 넘는 덩어리) → 속 안 마름 → 초벌 때 터짐(10 노트 7번). 핸드빌딩 오브제는 속 파내기 필수.
- 덜 마른 상태로 "다 말랐죠?" 하고 초벌 넣어달라고 함 → 손등 확인법 같이 해보면 납득함.

7. 건조 선반 관리 (강사 공통)
- 선반마다 이름표 카드: 반(화물/목핸/토물/원데이) + 성형일. 카드 없는 작품은 주인 찾기 지옥(06 노트 2025.06 밥공기 사건).
- 성형일 + 7일 지난 작품은 카드에 초록 점, 14일 지난 작품은 파란 점 → 초벌 담당이 파란 점부터 넣음. 초록 점은 손등 확인 후.
- 작품 목록(류쌤 관리)에 "건조 시작일" 칸 채우기. 초벌 가능일 계산용.
- 주 1회(월요일 오전) 선반 정리: 넘어진 것, 금 간 것, 이름표 떨어진 것 확인.
- 선반 위 먼지 → 젖은 걸레로. 마른 흙가루 쓸면 흡입 위험(실리카). 바닥도 물걸레가 원칙. 빗자루 금지(대표님).

8. 강사 체크포인트
□ 수업 끝날 때 모든 작품 비닐 여부 / 비닐 열어둔 정도
□ 손잡이·주둥이·얇은 테두리 따로 감쌌는지
□ 선반 카드(반·성형일) 붙였는지
□ 두께 2cm 넘는 부분 속 팠는지(핸드빌딩)
□ 분청·상감 작품은 일반보다 비닐 하루 더

□ 난방·에어컨 바람 직접 닿는 선반에 작품 없는지

9. 실제 사례
- 2024.11 B-2 난방 앞 건조 → 9점 분무로 살리고 2점 금(06 노트).
- 2025.01 한파, 밤사이 선반 온도 5℃ → 원데이 작품 2점 표면 부슬부슬. 겨울엔 퇴근 전 난방 최저 온도 설정(15℃) 켜두기로 함.
- 2025.07 장마철 2주 지나도 바닥 축축 → 초벌 미룸. 제습기 들임. 수강생 완성 날짜 1주 밀린 거 류쌤이 공지.
- 2026.03 목요일 핸드빌딩반 판 접시 6점 중 4점 바닥 가장자리 금 → 비닐 위에 바로 말린 게 원인. 그 뒤 판 접시는 무조건 석고판 + 신문지.
- 2026.09 원데이 수강생 머그 손잡이 이음새 금 → 원데이 마치고 바로 선반에 올린 것. 원데이 작품도 첫날은 무조건 비닐(원데이 담당 강사 체크).

10. 자주 받는 질문
Q. 언제 초벌해요? → 건조 7~14일 지나고, 가마에 작품이 30점 이상 모이면. 그래서 날짜가 매번 달라요(10 노트 3번).
Q. 금 갔는데 붙여주실 수 있어요? → 건조 단계면 메워보겠다고. 초벌 후면 메울 수 없다고 정직하게.
Q. 빨리 말리면 안 돼요? → 빨리 마르면 겉과 속, 얇은 데와 두꺼운 데의 수축이 달라서 금 감. 천천히가 제일 빠른 길이라고 말함.
Q. 흙이 왜 줄어들어요? → 물 빠지면서 줄고, 가마에서 한 번 더 줄어듦. 백자토 기준 성형 크기에서 13% 정도(새터 자료집 참고). 분청토 12%, 샤모트토 9%.

11. 메모
- (류쌤 의견: 건조 중 금 간 작품 연락은 사진 1장 + "건조 중 금이 가서 보수해 보겠습니다"까지만. 결과 장담하는 말 빼기)
- (대표님: 파손 처리는 정해진 기준 없음. 건조 중 금도 마찬가지로 대표님이 상의)
- (2026.11 추가) 제습기 물통은 아침 첫 강사가 비움. 가득 차면 자동으로 꺼져서 밤새 습도 오름.

13. 핸드빌딩 작품 건조 (목 19:30 핸드빌딩반, 일반 원데이)
- 판 성형(사각 접시·컵): 모서리 이음새가 제일 약함. 하루 비닐 + 모서리만 비닐 조각 하루 더.
- 코일링: 코일 사이 이음새를 안쪽까지 문질러 메웠는지 확인. 바깥 무늬로 코일 살리는 경우에도 안쪽은 반드시 메움. 안 메우면 건조 때 코일 사이로 금.
----- p.55 -----
- 핀칭(손으로 주물러 만든 컵): 두께가 들쭉날쭉. 손가락으로 집어 두께 확인하고 두꺼운 데는 속 긁어내기.
- 오브제·인형: 두께 2cm 넘으면 반 갈라서 속 파고 다시 붙이거나, 바닥에서 철사로 구멍 뚫어 속 파내기. 공기 빠질 구멍(바늘 구멍) 하나는 꼭.
- 원데이 작품은 수업 당일 강사가 두께 확인 후 비닐 → 이틀 뒤 비닐 열기 → 4일째 선반. 원데이 작품이 많은 주말 다음 월요일엔 선반이 꽉 차니까 위치 기록 철저히.

14. 재생흙 (건조 실패작·트리밍)
- 완전히 말라버린 작품, 금 가서 포기한 작품, 굽깎기 트리밍은 흙 종류별 재생통에(06 노트 색 테이프: 흰=백자, 회=분청, 검=흑토, 갈=산청·적토).
- 재생 순서: 마른 흙을 잘게 부숨 → 물에 담가 하루 → 위 물 따라냄 → 석고판 위에 펴서 반나절~하루 → 꼬박밀기(반죽) 충분히 → 비닐 보관.
- 재생흙은 공기 들어가기 쉬움 → 꼬박밀기 대충 하면 초벌 때 기포로 터짐(10 노트 7번 (1)). 재생흙은 연습용·원데이 연습 덩어리로만 쓰고, 정규반 완성 작품에는 새 흙 권장.
- 초벌된 조각은 재생 안 됨. 깨진 초벌 조각은 받침·테스트 조각용으로 E-5 바구니에.
